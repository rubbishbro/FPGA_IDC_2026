# ENG1 数据驱动鼓噪声合同（2026-11-02）

噪声开关由Flash记录的LFSR seed决定：seed=0禁用，seed≠0启用。
不新增enable、trigger、velocity等端口，ENG1保持原接口。
本合同替代此前的显式开关/tag提案；未生成或烧录鼓Flash镜像，未做综合/PnR。

## 槽布局与Flash位置

鼓件的手机配置与MIDI乐谱外部编号统一采用GM Note号：36/38/45/42/59/49，
依次查表转换为内部资源索引0/1/2/3/4/5；外部不发送0～5。
每件鼓起点为鼓组区起点加`drum_index*0x1000`，下文seed偏移再相对于该鼓件起点计算。
完整映射与当前未接入边界见[通信协议约定§3.2.2](通信协议约定.md#322-鼓组统一外部编号与内部索引2026-11-03冻结)。

`n_modes<=48`全部按ABC计算；`n_modes>48`时，前48槽为ABC，其后每两槽为噪声支路。
因此新布局的50/52/64槽不表示50/52/64个普通ABC模态。
当前普通ENG1资源仍使用48个有效模态，行为保持不变。
`router_pkg::n_modes_of(INST_DRUMS)`固定为52（48模态＋两条噪声支路），
不随seed开关变化；物理RAM深度仍为64。调用者也可固定用50槽表达一条支路。

每条支路两条记录，主槽48/50，扩展槽49/51。资源每个模态记录64字节：
相对于该鼓件系数资源起点，第一条seed在`0xC00`（48×64），第二条在`0xC80`（50×64）。
这是鼓件资源内偏移，不是绝对Flash地址；还须加镜像基址、乐器区及鼓件偏移。

| 主记录字段 | 记录内偏移 | 含义 |
| --- | --- | --- |
| a11 | +0 | LFSR seed，原始无符号32位；0关闭、非0启用 |
| a12 | +4 | 包络初值，UQ24，范围0..1 |
| a21 | +8 | 每采样衰减系数，UQ24，范围0..1 |
| a22 | +12 | 下截止一阶低通alpha，UQ24 |
| gq | +16 | 上截止一阶低通alpha，UQ24；0≤下≤上≤1 |
| gv | +20 | 非负增益，signed32 Q16 |
| wo | +24 | 保留，不作为tag或enable |

扩展槽的co字段保留，无需写入tag。主槽q/v保存LFSR/包络，
扩展槽q/v保存两个低通历史状态（signed32 Q24）。LFSR按位图读写，不走有符号饱和。
Flash加载仍使用原loader：读入co后由ENG1按地址解释，不需新增协议或引脚。

只将某主槽seed写0即可关闭对应支路；整条记录全0也可。另一条支路不受影响。
非零seed还须配合有效的包络、滤波与增益参数；无效参数按静音清状态处理。
仅烧录后要重新加载资源/重启，未重载的片内系数不会随Flash自动变化。

## 沿用原接口起音和清理

- `st_zero`始终优先，清状态并静音，不因正激励而同时重启。
- 清理后，运行LFSR为0且现有`x_data>0`时自动起音：装载seed和初始包络×min(x_data,1.0 Q24)，清滤波历史。
- 无正激励时，即使Flash seed非0也不自动发声；首帧激励为0时可等待后续正激励。
- 运行后`x_data`变化不重复触发，不持续改变尾音音量；下一次击打经现有`st_zero`重新准备。
- 维护清理/重载期间上层须使激励为0，否则清理后的正激励仍表示一次新击打。
- seed=0、非法参数、未收到正激励的零运行态会直接输出0并清两槽；不把LFSR=0映射为持续−1。
- 重载参数不会直接改状态RAM，须先清理旧范围，再演奏或缩小`n_modes`。
- 单独末尾残槽清零且不发声，不跨有效范围访问。

这一无新端口约定采用现有激励的正幅度作为起音力度，不能独立接收另一份velocity。
鼓前端仍待接入普通模态seed、尾音计时、Note-Off尾音语义及整机清理生命周期。

## 运算与验证

每采样LFSR bit0映射±1后推进右移Galois LFSR（mask `0x80200003`）；
噪声经两个低通之差整形、乘旧包络和Q16增益，饱和为signed32 Q24并加入64位声部和。
包络衰减后写回；乘法采用正半LSB舍入。公共腔体和混响仍在引擎外。
噪声与ABC分时复用原1R1W口，完整支路增加10拍，两条增加20拍，整机deadline待接入验证。

`python3 sim/run_eng1_noise.py`：417作业逐状态/输出/写次数对拍通过，
包括仅修改seed关闭/重启、非零seed空闲静音、无tag启用、连续激励不重触发、
清理优先、幅度钳位、非法参数、残槽、48/50/52/64边界、普通ABC及混合输出。
测试使用真实同步RAM读延迟；ENG1实例仅连接原端口。

Questa生产路由源码编译通过，`tb_midi_instrument_map`、`tb_performance_input_mux`通过，
日志在`build/eng1_noise_data_router/`。
