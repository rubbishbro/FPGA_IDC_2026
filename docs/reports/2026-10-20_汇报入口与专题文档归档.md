## 5. push 前注意（重要）

四份文档此前已被 `git add` 到 **旧路径**，现在移动后 `git status` 会出现：

```text
AD docs/B类迁移硬件估算.md
AD docs/双引擎统一顶层架构.md
AD docs/统一IIR合成数据格式与C类设计.md
AD docs/音色合成缺陷台账.md
?? docs/archive/2026-10/docs/...
```

`AD` 表示索引里还留着旧路径、工作区已删除。**直接 commit 会把旧路径的内容提交进去**。push 前请先让索引与磁盘一致：

```bash
git add -A docs/
git status --short docs/
```

预期看到旧路径为删除、归档路径为新增（`R` 或 `A`），再 commit/push。本次没有执行 `git add`、commit 或 push。
