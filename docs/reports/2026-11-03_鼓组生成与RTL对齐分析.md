原始模态为 `sum a*exp(-gamma*t)*sin(2*pi*f*t+phase)`。build_c_table使用r=exp(-gamma/fs)、a1=-2r*cos(theta)、a2=r²；按量化极点生成固定随机相位seed（CRC32鼓件名决定随机序列）。当前6件的有效主体模态数为48/48/27/48/48/48，量化后全部严格Jury稳定。

## 噪声生成与数据

当前NPZ六件均无LF/HF双尾音（gamma_lf=gamma_hf=0）。kick/snare/tom/hat各一条tail；ride/crash各tail+attack，共8支路，现有52槽布局足够。以后若同时有LF/HF+attack则需3支路，不能默默丢弃第三条。

提取器以1/3倍频程band_db生成257tap firwin2滤波器，端点有DC/Nyquist衰减并归一化sum(h²)=1。noise_gain按该噪声渲染器的能量校准，attack有自己的band_db。该noise_gain不能直接当作RTL带通增益。

fit_band枚举低/高截止候选，以目标频带的线性幅度拟合两低通差分响应：alpha=1-exp(-2*pi*fc/fs)。量化alpha后计算带通平稳RMS，最终应打包：

`gain_q16 = round(noise_gain * attack_multiplier * inverse_rms * KIT_GAIN[drum] * 65536)`。

不能把试听的全曲shared_output_gain或velocity重复烘进系数；力度应只在起音包络乘一次。当前compact增益为浮点，生产版需按RTL的先Q24包络乘法再Q16增益、逐级舍入/饱和重建参考。

以下为现有compact代码（fs=48828）重新计算出的候选，非已部署系数：

| 鼓件 | 支路 | 拟合截止Hz |
|---|---|---|
| kick | tail | 30～60 |
| snare | tail | 100～180 |
| tom | tail | 30～60 |
| hat | tail | 12000～18000 |
| ride | tail / attack | 500～8000 / 12000～18000 |
| crash | tail / attack | 3800～5500 / 500～1200 |

8支路量化后均满足0<alpha_lo<alpha_hi<2^24、0<decay<2^24，Q16增益正且可表示。截止结果不能视为原FIR等价，特别是snare窄带候选需要听感和频谱核对。compact脚本的旧FIR参考在DC/Nyquist平铺端点，当前percussion.py已加入端点衰减，二者不是同一算法。

## 当前RTL记录合同

`eng1.sv`在n_modes>48时，将0～47解释为普通ABC；48/49、50/51分别为一条噪声支路。鼓固定n_modes=52，物理每件仍64×64B=4KiB。

| 噪声主槽co字段 | 偏移 | 打包含义 |
|---|---:|---|
| a11 | +0 | 非零u32 LFSR seed；0关闭 |
| a12 | +4 | 初始包络UQ24，<=1 |
| a21 | +8 | 每采样包络衰减UQ24 |
| a22 | +12 | alpha_lo UQ24 |
| gq | +16 | alpha_hi UQ24 |
| gv | +20 | 正signed32 Q16 gain |
| wo | +24 | 保留 |

扩展槽co保留，不放FIR系数，不需要tag。主槽运行q/v保存LFSR/包络，扩展槽q/v保存两个低通历史。LFSR右移Galois mask=0x80200003，当前bit0映射±1，使用该位产生本帧输出后推进。

矩阵/ABC及噪声共享原1R1W RAM端口，loader字段搬运能力已足够装入噪声记录；但当前abc_record、pack_board_flash格式判定和资源检查器都按旋律ABC处理，不能将其不加区分地用于52槽鼓资源。

起音时噪声要求：st_zero先清理静音，再在运行LFSR为0且x>0时装载seed和初始包络*min(x,1)。持续x变化不重触发。普通ABC的st_zero只清历史，仍会计算G*x；因此“st_zero与单拍正冲激同帧”可能只启动主体而没有启动噪声。推荐明确清理帧x=0、下一帧正冲激且st_zero=0的序列。

## 必须对齐的差异与建议

1. **主体起音方式须先确定。** 原代码G=0，Flash loader不装y1/y2，原样打包必然无模态声。若保留当前不增加seed入口的核，需正式化冲激G生成；它改变模态相位，不能宣称等价。已有历史冲激试验在力度0.8时signed版本与seed参考：snare RMS差-5.06dB、相关系数0.355；kick RMS差-1.82dB、频谱RMSE38.2dB。该历史产物仅供决策，未在本次重跑音频。若优先保留原参考声音，建议新增明确的鼓起音seed装载语义，复用现有co保留字段和q/v RAM，不把seed伪装成持续音参数或泛化st_zero。需要同步定义初始化帧与噪声起音帧。
2. **统一采样率。** 主体build_c_table/冲激试验用48000；compact噪声用48828；生产资源清单为48000，实际音频时钟仍须按板级合同核对。建议一个生成参数fs贯穿全部模态、alpha、decay、时长及试听，先按当前生产48000口径生成，不改其它乐器。
3. **合并生成器而非拼接试听产物。** 新建鼓专用record生成接口：前48主体、不足补零；48/49=tail、50/51=attack；单支路第二对全零；52～63保留。P1T1仅适用主体且鼓不启用调制；噪声按地址解析专用字段。检查器对ID7分段校验，保持其它乐器严格ABC约束。
4. **尾音寿命必须上收管理。** 噪声RTL没有时长/结束计时，Q24包络四舍五入会停在非零台阶（本批约286～33689 LSB），不可等待它自然精确归零。原参考有timer+fade/choke，当前鼓env是普通gate旁路，MIDI Note Off会截断；需要鼓专用生命周期：忽略Note Off对尾音的直接清除，到期淡出并hard-clear、回收槽位，维护时强制静音。重击/同组choke是否保留旧尾5ms交叠须明确；同一槽原地清除并不等价于试听的旧尾重叠。
5. **噪声参考改为实际整数核。** 保留现有非零seed开关，无需新tag；按当前percussion.py生成FIR对照，用两低通拟合后量化并以oracle对拍。稳定性要求宜比RTL输入合法性更严：衰减<1、启用低通alpha>0，检查尾噪、增益/内部饱和、频谱拟合误差。
6. **最后接入映射和镜像。** 继续沿用六件GM号36/38/42/45/49/59→内部索引0～5（按GM升序，2026-11-03确认）；ID7区域0x8E0000，六件起点0x8E0000～0x8E5000，每件4KiB。seed地址=鼓件起点+0xC00和+0xC80；公共控制页仍0x980000，32位置步长不变。先通过新鼓整机加载/重击/尾音/deadline回归再开放掩码bit7及第10通道；本次均未开放。

## 补充：FIR拟合、现有激励及RAM复用

RTL实际是两个一阶低通之差，不是只能做单低通。L_lo+=alpha_lo*(white-L_lo)，L_hi+=alpha_hi*(white-L_hi)，整形结果为L_hi-L_lo。当alpha_lo=0且该历史经起音清为0时，低路恒0，即退化为纯一阶低通；切换配置后必须清旧历史，不能只改alpha。

本次以percussion.py当前257tap FIR频响为目标，fs=48000，在DC及20Hz～Nyquist的240个对数频点上，多起点拟合连续alpha和正标量增益，再量化Q24。指标为相对幅度L2误差（不是dB、不是听感评分），结果在build/drum_filter_fit/results.json，复现脚本同目录fit.py。候选集中包括alpha_lo=0的单低通边界，不证明全局最优。

| 噪声 | 单低通误差% | 当前RTL可选最佳结构误差% |
|---|---:|---:|
| kick tail | 9.5 | 9.5，单低通，等效参数fc约126Hz |
| tom tail | 10.8 | 10.8，单低通，约112Hz |
| snare tail | 19.8 | 19.8，单低通，约1087Hz |
| hat tail | 76.9 | 19.0，两低通差分 |
| ride tail | 47.9 | 16.8，两低通差分 |
| ride attack | 75.9 | 47.4，两低通差分 |
| crash tail | 65.9 | 40.4，两低通差分 |
| crash attack | 73.5 | 57.5，两低通差分 |

高频噪声的单低通拟合趋向直通，仍有大误差。建议正式生成器同时枚举单低通边界及双低通差分，直接拟合实际量化滤波器；拟合目标要与当前FIR的DC/Nyquist端点处理一致，并单独校准RMS/包络能量。ride/crash剩余误差较大，不应仅凭系数合法就宣称原噪声等价。最终Q16增益/输出饱和也须回到整数oracle检查。

现有excitation_gen有有限拨弦/击锤（线性上升、指数下降、可设置重复次数）、按住重复（N_PULSE=7能力）、持续音周期单采样冲激；另有trumpet_excitation独立的双极唇振+起振扰动+气流噪声。鼓当前case只是32采样拨弦占位。

可原样复用吉他的短拨弦或现有鼓32采样拨弦，重新校准主体G，作为近似鼓激励。有限拨弦实际在GAP_LEN=0、N_PULSE=0时到达峰值后很快被清空，不是任意长的自由指数尾。N_PULSE=0也不会自动变成单采样冲激。现有周期冲激分支可抽出只发首个冲激的one-shot控制，但目前没有该控制；不能仅将鼓设为is_sustain，否则会周期重敲且牵连包络/逐音period校验。小号气流噪声在模态之前，不能替代ENG1中并联加入输出的鼓噪声。

voice_router在系数ca_* RAM和状态q/v RAM各自沿用{bank内声部,mode}地址。普通ABC槽的ca_a11/a12/a21=G/a1/a2、q/v=y1/y2；噪声主槽改解释七个co字段及q/v=LFSR位图/包络，紧邻扩展槽q/v=两低通历史，co保留。它复用的是系数RAM和状态RAM，不是pm_*调制参数RAM；pm_*仍由Flash记录+32～+60单独装载。每支路占2个mode地址、4个状态字=16字节；两支路32字节/声部。系数及状态读写在ABC结束后分时进行，每bank仍只有既有读写口，不增加FIR延迟线或额外多读口RAM。
