# 六音色最终PCM输出对比（2026-11-03）

这是RTL仿真结果，不是板卡模拟录音，也不是从运行中板卡回传的PCM。以05ccb82c音频RTL与板卡实际Flash回读镜像（SHA256 bafcf17e2af23975826a47fd4ed00c967cbdd3f278781814ffa4ae6c0e8f71d1）运行：真实QSPI loader→激励/包络/模态引擎→逐乐器RMS增益→琴体→NONE混响→居中声像/ITD→PCM16→异步FIFO→PT8211串行输出。直接从输出BCK/WS/DIN解码左右声道。

条件：16槽/64存储模态、PAD阈值64/48、压力255、低音组slot15、h=0、声像16居中、混响NONE，复音增益按该版RTL临时bypass。每种音色独立复位并真实加载，单音按住4096帧（83.88608ms），松开后再采4096帧；没有按文件自动增益或峰值归一化。

实际采样率48828.125Hz，20ms窗口取977样本。RMS按两声道分别计算；本次左右数据逐样本完全相同，因此下表列单侧。0dBFS参考32768。发声段RMS仅计按住期间4096帧，最大20ms RMS使用完整8192帧的滑动窗口。
