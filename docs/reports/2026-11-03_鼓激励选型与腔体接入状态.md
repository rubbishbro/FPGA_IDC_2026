# 鼓激励选型与腔体接入状态

## 已应用

用户选择“同峰值、缩短上升段”组中的rise_sh=3版本。当前exc_router的INST_DRUMS已改为SHIFT=16、RISE_SH=3、PW_LEN=8、GAP_LEN=0、N_PULSE=0；对应48kHz下约0.167ms上升。不是固定PW32、仅加快步长的另一组。模型约定`drum_coefficients.DRUM_EXCITATION`同步。

沿用现有excitation_gen，不增加模块、状态RAM或调制。鼓组仍未开放生产资源掩码、未接GM映射和尾音生命周期。现有统一鼓增益2022保持原值；它来自此前one-shot标定，本次激励形状变更后尚未重新标定噪声平衡和鼓增益。

实际RTL测试涵盖1/2/8/32采样脉宽、四档力度、重触发和清理，共1536采样通过。资源清单源哈希已刷新，系数镜像字节不变。

## 当前腔体参数

所有音色共用voice_router混音后的body_router，再进入混响。不是每个声部独立腔体；参数来自RTL常量，不从Flash加载，也不使用旧body ROM生成器。

| 乐器 | 非直通biquad数/总段数 | 当前来源/接入状态 |
|---|---|---|
| 钢琴ENG0 | 3/5 | sythsound/sim_piano.py::PIANO_BODY_BIQUADS_3，3段实装，后2段直通 |
| 钢琴ABC | 2/5 | 独立40Hz高通+2kHz/+3dB棚式EQ，后3段直通 |
| 吉他ENG0 | 5/5 | sythsound/sim_guitar.py::BODY_BIQUADS，5段实装 |
| 吉他ABC | 5/5 | body_inst显式映射到INST_GUITAR，完整复用上述5段 |
| 长笛/小号/大提琴/小提琴/双簧管 | 0/5 | 默认5段直通，无专用腔体参数接入 |
| 班卓琴/曼陀林 | 0/5 | 默认直通；已有对应FFT_results/params/*_body.npz，但当前通路未加载 |
| 鼓组（未启用） | 0/5 | 默认直通；ENG1内噪声低通与这里的公共腔体是不同处理层 |

每段参数为b0/b1/b2/a1/a2，signed32 Q4.27，反馈符号为减a1*y1、减a2*y2。直通段为[2^27,0,0,0,0]。

本次按量化系数检查全部段严格Jury稳定；钢琴ENG0和吉他参数与上述sythsound浮点表进行floor(c*2^27+0.5)量化后逐项完全相同。核查产物为build/body_connection_audit/results.json。

旧`python/modal_sim/gen_body_rom.py`生成4段/Q30 ROM，包含班卓琴、曼陀林，但不属于当前5段/Q27常量body_router路径，不能把“已有生成器/NPZ”当作当前已接入。若后续增加专用腔体，需要格式转换/稳定性验证，并重新标定对应乐器输出增益。
