# 力度响应与新增音色增益标定（2026-11-04）

> 阶段报告：结论与验证范围以报告日期为界，当前状态见[状态页](../status.md)。旧构建产物已按交稿要求清理，文中旧路径保留作历史定位。

本次调整的是板端 PAD 压力对应的音高变化。它随按压力度变化，没有新增周期性 LFO。

## 力度响应

- ABC 引擎的 `modulation1` 从每档 0.6 音分提高到 0.75 音分，即提高 25%。Q8 实现为每档精确 192，保持原流水级数。
- 默认阈值 102 时，压力 102 / 152 / 202 / 255 对应 0 / 37.5 / 75 / 114.75 音分。松键仍保持最后提交值。
- 矩阵吉他的 `modulation0` 上限由 Q30 的 37,580,959 提高到 46,976,199，同样增加 25%；仍只更新前四个模态。
- Python 整数模型补齐 MAP_CENTS / MAP_RATIO 流水阶段，与 RTL 周期对应。

## 标定条件与结果

沿用原有六种乐器的 MIDI 69、满力度 255、单音、关闭力度调制、启用腔体、混响 NONE、PCM_HEADROOM_BITS=0。以 960 点（20 ms）滑窗最大 RMS 作为幅度指标，目标 −12 dBFS；新增旋律乐器在参考音上另保留至少 1 dB 峰值余量。鼓组使用六个实际 GM 鼓件，以最响鼓件为统一增益参考。

| 乐器 | 旧 Q12 增益 | 新 Q12 增益 | 参考最大 20 ms RMS（dBFS） |
| --- | ---: | ---: | ---: |
| 双簧管 | 3321 | 3321 | −12.00 |
| 班卓 | 1097 | 1025 | −12.23 |
| 曼陀铃 | 1543 | 1244 | −13.52 |
| 钢琴 2 | 10992 | 10159 | −12.68 |
| 吉他 2 | 1165 | 1165 | −12.00 |
| 鼓组（最响鼓件） | 453 | 453 | −12.00 |

原有钢琴、吉他、长笛、小号、大提琴、小提琴的增益不变，复测参考 RMS 均约 −12 dBFS。曼陀铃因参考峰值约束，保留约 1.52 dB 的 RMS 差异。

修复了旧标定脚本跳过班卓、曼陀铃包络的问题，改用当前生产 ADSR；鼓直接读取生产 Flash 系数及实际 strike/包络，避免再次叠加已写入系数的 `reference_balance`。

MIDI 60 / 69 / 72 另作范围探测。这是同音高参考标定，不代表整个音域或多音混音均不会削波：满力度 MIDI 72 的班卓和曼陀铃峰值分别约 +1.45 / +4.10 dBFS。没有修改按音高校正或混音动态策略。

## 仿真与复现

`sim/tune_added_instruments.py` 分为三步，输出到 `build/timbre_tuning_20261104/`：

```sh
python sim/tune_added_instruments.py --stage render --workers 4
python sim/tune_added_instruments.py --stage calibrate --apply
python sim/tune_added_instruments.py --stage rtl --workers 4
```

Python 环境需要 NumPy、SoundFile、SciPy；RTL 步骤需要 Questa 的 `vlib` / `vlog` / `vsim`。

RTL 测试使用生产 `exc_router`、`env_router`、ENG1、`body_router`，逐采样核对前端输入、包络、引擎和腔体输出，按生产顺序执行包络与 Q12 增益运算，再核对 PCM16 转换。五种旋律乐器使用 MIDI 69，鼓组覆盖六件；旋律乐器保留 5 秒输出（双簧管 9 秒），鼓件各 3 秒。这是单声部无混响链路验证，不包含 Flash 传输或物理 I2S 时序。

主要产物：

- `gain_decisions.json`：增益、参考 RMS / 峰值、范围探测。
- `original_reference_comparison.json`、`original_six_reference_model.wav`：原有六种乐器的整数模型参考；`original_reference_then_added_rtl.wav` 将原参考与新增 RTL 输出接续播放。
- `*_rtl_pcm.wav`、`added_instruments_rtl_comparison.wav`：实际 RTL PCM16 输出；顺序为双簧管、班卓、曼陀铃、钢琴 2、吉他 2，然后按资源清单排列的六件鼓。
- `rtl_verification.json`：11 组共 2,256,000 个采样全部通过，参考音 PCM 削波计数与腔体饱和计数均为零，附源文件 SHA256。
- `pytest.log`：31 个生产整数模型单元测试通过；连奏试听辅助脚本也已同步新压力映射。
- `aftertouch/results.json`：1041 次作业、6240 次系数检查；Python / RTL 40,000 周期一致。
- `modulation0/`：三个阈值、256 档压力的 46,080 次系数核对，以及两引擎调制通道切换检查。
- `mod1_budget/results.json`：小提琴、双簧管、曼陀铃、吉他 2 的满 16 声部调制预算，最大音频延迟 601 / 1024 拍。
- `production_stability.json`：98,304 个矩阵调制点、1,497,024 个 ABC 调制点均通过整数极点稳定性检查。这不替代动态溢出检查。
