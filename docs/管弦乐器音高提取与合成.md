# 管弦乐器的音高提取与持续音合成

2026-10-23 源码复核。重点为小号 trumpet、小提琴 violin；本轮只调研和运行数值检查，不修改提取／合成算法，也未冻结 32 音键位。

## 1. 结论

两件乐器共用 `python/fft_analysis/sustain.py` 与 `python/modal_sim/sustain_engine.py`，不是分别实现一套音高算法。

**现有 Python 模型已经能够借用最近音符的音色参数，为目标 MIDI 重新生成模态频率与系数。** 原始录音／提取表不连续，不等于合成器不能产生连续音高；但当前采用最近邻音色选择，不是相邻音符参数插值，且尚未完成完整板端系数表及持续激励前端。

FFT 只用于离线提取参数。合成时是周期激励驱动二阶模态谐振器，不是逐帧 FFT/IFFT，也不是播放原始采样。

## 2. 样本怎么进入提取流程

入口：`sustain.scan_sustained()`，`python/fft_analysis/sustain.py:45`。

```text
music_resources/trumpet/*.mp3
music_resources/violin/*.mp3
  → 从文件名读取音名、时值、力度、奏法
  → 筛选 very-long / long / 15
  → 筛选 forte / mezzo-forte
  → 筛选 normal / arco-normal
  → 加载、单声道化、重采样到 48 kHz
```

文件名里的音名提供 nominal MIDI，作为基频搜索的先验，而非最终测量值。

本次实际库存：

| 乐器 | 所有可识别命名的录音数 | 通过当前筛选的录音数 | 提取表不同 MIDI 数 | MIDI 范围 |
|---|---:|---:|---:|---|
| trumpet | 485 | 44 | 32 | 51..88，非连续 |
| violin | 1502 | 52 | 40 | 55..103，非连续 |

通过筛选的录音数量与现有 `.npz` 条目一致。并非全库只有这些音高：小提琴 9 个缺失 MIDI 在完整库里都有录音；小号 6 个缺失 MIDI 中有 5 个在完整库里有录音，只是未通过当前筛选。若想扩大提取覆盖，可以先检查这些录音是否有足够稳态，而不是直接认为样本不存在或无条件放宽筛选。

## 3. 如何测基频和泛音

### 3.1 找稳态段

`sustain.analyze_sustain()`：

1. 用约 10 ms RMS 包络检测发声区间，门限为峰值的 10%。
2. 首选发声区间中间 30%..70%；若不足 0.4 s，改用 15%..末端。
3. 稳态段峰值归一化，加 Hann 窗；`core._spectrum()` 做至少约 2 倍长度、向上取 2 的幂的零填充 FFT。

这里避免从小号起音瞬态或小提琴起弓噪声中直接读音高。零填充让频率采样更密，不等于提高录音本身的真实频率分辨率。

### 3.2 基频不是“最大谱峰”

`core.estimate_f0()`，`python/fft_analysis/core.py:279`，使用 TWM（two-way mismatch）：

- 当前持续音调用在 nominal Hz 的 ±8% 范围搜索候选 f0。
- 候选整数谐波列与强谱峰双向匹配：预计谐波是否能找到峰、强峰是否能被谐波解释。
- 综合误差最小者为 f0，并对候选分数作局部细化。

因此即使二次泛音比基频更响，也不必把音高误判成高八度。这是已知文件名音高附近的校准，不是无先验的任意多音 MIDI 转录。

### 3.3 泛音定位和幅度

`core.find_partials()`，`python/fft_analysis/core.py:387`：

- 在预测泛音附近找峰，一个谱峰最多分配给一个泛音，避免重复模态。
- 用对数幅度三点抛物线细化峰频率。
- 先估计非谐性，再搜索完整泛音列；当前提取默认最多 48 个模态，分析上限 16 kHz。
- 对颤音导致的谱线旁带，`analyze_sustain()` 先估计频率摆幅，再对每个泛音附近的功率积分并开方，归一化得到权重 a_k；不是只取单个 FFT 峰值。

### 3.4 其他参数

- `gamma_k = pi * FWHM_k`，从每条谱线的半功率宽估计谐振器阻尼，限制到 0.3..400；有足够有效点时用频率趋势填补缺失。
- 注意窗函数、有限时长和颤音也会展宽谱线，该 gamma 是模型估计，不应当作已分离所有影响的真实物理阻尼。
- 记录 attack、release、泛音间噪声水平及 24 个频带的噪声形状。
- 输出 `FFT_results/params/trumpet_sustain.npz`、`violin_sustain.npz`，保存 MIDI、力度、实测 f0、k、f_k、a、gamma、包络与噪声描述等。

## 4. 缺失音高怎么生成

关键：`SustainPatch._pick_key()`、`SustainPatch.modes()`，`python/modal_sim/sustain_engine.py:140`。

选择音色数据的顺序：

1. 当前音高的目标力度。
2. 当前音高的其他可用力度。
3. 距离最近的已有音高及其可用力度，同距离优先较低音高。

**借用的是泛音序号、幅度、阻尼和包络等音色描述，不是照搬源音符的频率。** 目标 MIDI 会重新计算：

```text
f0_target = 440 * 2^((midi - 69) / 12)
f_k       = k * f0_target       // 用于模态筛选
```

此路径故意使用整数谐波，并未直接重放提取时略微失谐的 `f_k`。提取的实际 f0 用于正确分配泛音；合成音高则重新以目标 MIDI 为准。

当前没有相邻两个音符之间对 a/gamma/attack 等参数做加权插值。移调距离增大或跨过最近邻分界时，音色连续性需另行验证。

## 5. 如何持续发声

`SustainSynth._start()`，`python/modal_sim/sustain_engine.py:332`：

```text
T       = round(fs / f0_target)
f_drive = fs / T
f_k     = k * f_drive
r_k     = exp(-gamma_k / fs)
a1_k    = -2 * r_k * cos(2*pi*f_k/fs)
a2_k    = r_k^2
G_k     = w_k / A_unit_k
```

`A_unit_k` 是单位周期激励下该谐振器的稳态幅度，`steady_amp_unit()` 计算它，以使合成泛音权重接近提取权重。

逐样本运行：

```text
周期脉冲 × 起落包络 × 力度 × 幅度调制 → drive[n]
y_k[n] = G_k*drive[n] - a1_k*y_k[n-1] - a2_k*y_k[n-2]
输出 = 各模态 / 各声部求和
```

可选颤音同步改变激励频率与模态频率，避免两者失谐。气息／弓噪声有实现但默认关闭。小号在 `sustain_demo.py` 有专门表现力预设，小提琴未列入该 demo 的 VOICE 表，但可使用通用 SustainPatch/SustainSynth；不能把通用可运行等同于已有完整小提琴专用调参验收。

这属于录音频谱参数驱动的持续音模型，并非完整的唇簧／弓弦非线性物理模型。

### 当前音准限制

虽然脉冲发生器用小数相位累加，初始 `f_drive` 已被整数 T 量化，因此仍有音准偏差。仅将相位累加器改名为 DDS 不能消除这一点。

若后续改为精确目标频率驱动，必须同步处理模态频率，并重新核对非整数脉冲间隔下的稳态增益校准；不能只改一处而继续假定旧校准完全成立。

### 6.2 连续 32 音的生成检查

以下仅为测试区间，不是最终键位选择：

| 乐器 | 连续测试区间 | 其中借用邻音参数的 MIDI | 生成模态数 | 整数周期最大音准偏差 |
|---|---|---|---|---:|
| trumpet | 57..88 | 59、60、66、68、78 | 11..48 | 19.3545 cents |
| violin | 67..98 | 69、72、73、77 | 6..40 | 36.9508 cents |

全部 64 个目标音符都完成参数／系数构建与 256 样本脉冲列响应检查：系数、输出均有限，输出非零，静态极点半径小于 1，生成模态低于 Nyquist。调制与噪声关闭。

例：trumpet 的目标 MIDI 60 借用 `(61, forte)` 音色数据，但驱动为 262.295082 Hz，而非 MIDI 61 的频率；与 MIDI 60 理论值 261.625565 Hz 的差别来自整数周期。violin 的目标 77 借用 `(76, forte)`，同样按目标音高重新生成。

这些是短时 Python 模型检查，不代表长时听感、定点量化、颤音稳定性、硬件实时性或板级验收。

## 7. 对 16×2 键位方案的含义

两件乐器都不必因为提取表稀疏而强制使用不连续键位。可以在合理音域内选连续 32 个目标 MIDI，离线用现有模型生成，再冻结为板端表。

但要显式区分“实测音符”和“邻音参数移调生成”，并先决定音准策略。板端仍需补齐正式 B 类系数／控制表、周期激励、逐声部包络与事件调度；当前 Python 能生成，不等于板端已有完整闭环。
