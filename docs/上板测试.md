# 上板测试

适用：`build/performance_led_joy_flash/`中的配套固件与资源（已烧录并校验，包含LED位序及摇杆上下修复）。以下是待执行的实板测试方案，不是实板通过记录。

## 准备与固定条件

- 固件地址0；768KiB资源BIN地址0x800000。分别校验写入内容，更新其中一项时保留另一区域。
- 完成Flash写入后断电重启，不能只验证SRAM临时下载。
- 首轮混响选NONE，声像保持本固件默认居中，外部音箱/声卡增益固定，录音关闭自动增益、降噪、压缩和归一化。
- 先用有线MIDI获取可复现结果，再用压力垫测真实演奏；两者力度路径不同，不要求相同输入数字产生完全相同音量。
- 有线UART为115200、8N1、协议v1。当前包的BT_PROTOCOL_V2=0，不能使用v2心跳/会话故障测试。
- 一次只选择一种音色/一个接收通道；不支持六音色同时混奏。切换时停止走带，松开压力垫，等待板端完成加载后再重新播放。

| 吉他1 | 1 | eng0 | 1（0） |

## 当前固件可直接执行

| 编号 | 操作 | 通过标准/重点观察 |
|---|---|---|
| T01 冷启动 | 断电重启5次；每次加载并弹奏钢琴1，再切换钢琴2 | 自动启动；显示、资源加载及发声正常；不依赖下载器保持连接 |
| T02 编号和UI | 逐一选择六种音色；核对标签、通道，按一个键 | 钢琴1/2、吉他1/2标签清楚；通道与上表一致；无加载失败、错表或无声 |
| T03 全音域 | 每种音色依次播放全部16音，每音0.3～0.5s，留松键间隙 | 无漏音、串音、局部异常巨响、明显错八度；逐个实体垫核对对应音高和显示 |
| T04 新旧对照 | 同一16音短句、相同力度96，分别录钢琴1/2、吉他1/2 | 新旧都能独立发声，起音能量在同一量级；允许音色、自然衰减与峰值不同，不要求波形一致 |
| T05 力度 | 同一音按32/64/96/127力度播放，各重复3次 | 强弱方向正确、重复稳定、最大力度无新增破音；不要求线性响度比例。压力垫另测轻/中/重压 |
| T06 包络与release | 每种音色做短按50ms、中按200ms、长按2～5s后松键；混响NONE | 小号/小提琴可持续发声，松键后有释放；钢琴/吉他保持自然衰减。无意外断裂、卡音、重触发双击；小提琴释放约80ms、吉他满幅包络释放约600ms仅作参考，实际还受模态/body尾音影响 |
| T07 同音重触发 | 同音按下/松开各50ms，重复20次，再换相邻有效音交替 | 每次起音可辨，无逐渐积累的残音、偶发静音、爆音或旧状态带入 |
| T08 复音增益 | 固定力度96，按有效音表前N音测试N=1/2/4/8/16；再做错开起音、16音逐个松到1音，最后全松 | 所有音均可辨，无明显掉拍/破音；加声部不应出现失控增大，减声部不应瞬间跳大。release仍计入N，增益恢复有平滑，不要求不同和弦RMS完全一致 |
| T09 延音与清理 | CC64=127，弹奏后发Off，再CC64=0；分别测试CC123=0、CC120=0及本地“清音” | 踏板释放后进入正常释放；CC123受踏板规则影响，不能当硬清音；CC120清声部。本地清音完成后可重新演奏，无永久卡音，不把UART发送完成当作设备清音完成 |
| T10 切换与mux | 按钢琴1→钢琴2→吉他1→吉他2→小号→小提琴→钢琴1循环10次，每次等配置完成后弹相同短句 | 两引擎反复切换均正常，无旧音色/尾音带入、错增益或死锁；压力垫持键切换时可提示“请松手”，不是加载失败 |
| T11 混响 | 通过本地菜单依次NONE/HALL/BATHROOM，短句后全松；每次等配置完成 | 三者有合理差异；尾音自然结束，无持续振荡或积累破音。切预设可能清音/重载，不要求无缝切换 |
| T12 居中双声道 | 用板载3.5mm输出录立体声，播放单音及和弦，分别监听L/R | 两声道都有声、居中无明显偏移；相同通道链路下L/R应接近。可把RMS差≤0.5dB作为模拟链路排查参考，非既有实测保证 |
| T13 来源与引导 | PAD→有线MIDI→PAD；有线下测自动/引导演奏。蓝牙可选做v1正常演奏 | 非选中来源不触发新音；引导时仅发MIDI提示不自动发声，实体垫按下才发声；切换后无卡音。普通v1 UART静默拔线不能假定自动识别断线 |
| T14 长时负载 | eng0与eng1各选一种，16音和弦/快速琶音/踏板循环各15分钟；补测HALL，再复位重启 | 无新增断裂、卡死、持续噪声、输出消失或UI失灵；有异常时保存时间点及输入片段，不只描述听感 |

| T15 灯光连续性 | 不按键观察至少两个5.2s背景周期，再单击/连击压力垫 | 灰度变化不再出现位序反转造成的骤亮骤暗；彩色波纹颜色稳定，按住不重复触发 |
| T16 摇杆方向 | 上电保持松手校准，再分别推上/下/左/右 | 相比上一版上下互换、左右保持；光标方向符合实际要求，回中不漂移 |

建议顺序：T01～T04先确认镜像和路由；T06～T10重点验收本轮前端、增益与mux；最后做混响、来源和长时测试。

## 录音和仪器复核

1. **增益对齐**：固定模拟增益，六种音色各录16音，力度127、混响NONE。比较起音前200ms内最强20ms RMS，同时保留峰值。模型目标为-18dBFS，但模拟录音绝对值受DAC/耳放/声卡增益影响，优先比较相对差异。不要逐文件归一化。
2. **断裂定位**：记录异常时的音色、音高、力度、按住/松键、踏板、复音数及混响；保留前后至少1s音频和相应MIDI。区分正常短包络、重触发、增益恢复与突发缺样。听不到异常不能证明deadline计数为0。
3. **数字音频**：有逻辑分析仪时采BCLK/WS/DIN，分别按外接标准I2S与PT8211格式解码；两种格式不同，不能复用错误解码设置。当前输出是16bit/声道。居中时数字左右样本应相同；用数字录波检查削顶、突发零样本及左右配对，并与相同输入的模型比较。
4. **采样率/音高**：板级12.5MHz音频时钟按256分频，实际Fs=48828.125Hz；资源清单resource_fs=48000。48k离散响应按此时钟直接播放会有约1.73%的时间/频率比例差（约+29.6音分）。必须单列测量，不能把48k模型WAV与板端直接按同时间轴比较；最终音准需逐音测实际输出。小号/小提琴还有周期激励及取整因素。

## 需要额外测试构建/诊断入口的项目

- **左右端点和扫声像**：默认STEREO_PAN=16、AUTO_SWEEP=0；可在“效果 → 声像”运行时设置0/16/32，配置ID为0x0102，CC10仍未接入。自动扫仍需单独构建，并对该固件重新做时序验收。详见[声像配置](声像配置.md)。
- **1/sqrt(N)开关A/B**：当前包始终启用，不能运行时关闭；要做严格听感对照需要独立测试构建，保持系数、headroom、输入与模拟增益一致。
- **硬件deadline/overflow/underflow读数**：系统内有三项诊断，但instrument_board_top未引出。需增加片上逻辑分析或可读状态；当前LCD/UART不能直接读取这些计数/标志。
- **唇振不稳定/气流噪实验**：本包小号仍是RTL周期冲激前端；不能把此前Python的唇振/气流实验作为已经上板的功能验收。

## 建议记录格式

`日期/固件SHA/资源SHA/测试编号/音色与通道/音高与力度/来源/混响/复音数/录音路径/通过或失败/异常时间点`

至少保留：六音色16音单音录音、新旧钢琴/吉他相同短句、1→16→1声部录音、小号/小提琴长按后松键录音。这样发现问题后能重放同一输入并与Python/RTL仿真对照。
