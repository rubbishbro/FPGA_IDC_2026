# 双声道空间定位

位置处理放在 `i2s_audio_output` 内：全声部混音、腔体、混响之后，PCM16 量化及异步 FIFO 之前。整体声音和混响尾音作为一个声源移动。算法文件为 `rtl/audio/stereo_spatializer.sv`，不修改合成引擎，不使用乘法器、CPU 或 DDR。

## 位置与增益

`pan_position` 是同 core 时钟域的 6 bit 输入：0 最左、16 居中、32 最右，大于32钳到32。左右原始比例为 `(32-pan):pan`，离线将最大一侧归一到1，另一侧保留比例。即 `gL=(32-pan)/max(32-pan,pan)`，`gR=pan/max(32-pan,pan)`，RTL只查表、插值和移位加法，没有对输入音频做除法。

2026-11-01已替换此前等功率声像：33档Q8系数，中心从181/256改为256/256。中心每声道恢复约3dB；两声道总功率比单侧高约3dB是本次要求的结果，不作为误差。全部513个Q4位置均满足 `max(gL,gR)=4096`（Q12）。ILD比例受Q8量化与插值精度限制；ITD、平滑与26拍延迟保持原接口。

平滑位置使用 Q4，每帧最多前进 1/16 档；相邻 Q8 系数线性插值，保留 Q12，不在插值后截断。整个左右行程 512 帧，48 kHz 时约 10.67 ms；这是从一个端点跳到另一个端点的平滑时间，不是新增音频排队延迟。

## 辅助 ITD

只有一个位置控制。偏左时右声道较弱并稍晚，偏右相反；中心无差分延迟。默认最大 4 样本，可综合参数选择 0/1/2/4/8。延迟取决于平滑后的位置及 `itd_enable`，无独立方向/时差控制。开关 ITD 时延迟也渐变。

使用 Q6 分数延迟，相邻两个 ILD 历史样本线性插值，跨整数抽头时连续过渡。线性分数延迟会引入频率相关的幅度变化，不将其宣称为理想全通延迟；首版应分别试听 ILD 和 ILD+ITD。

## 数值、节拍和接口

64 bit Q24 输入，13 拍串行移位加法计算左右 Q12 增益，再用 6 拍移位加法计算 Q6 分数延迟，保留额外 18 位小数和保护位，最后统一舍入/饱和到 PCM16。模块增加位置/LUT读取、4拍系数插值及抽头读取寄存器后，从接收样本到 out_valid 为 26 个 core 周期；桥接/FIFO另有寄存器传递开销，不增加完整音频帧。

按 I2S CDC 返回的 `sample_tick` 每帧送入一笔，包括计划静音或缺失结果补零。`clear` 在该帧边界生效，输出静音并使旧 ITD 历史不可见；不撤销已进入 FIFO 或正在播放的数据，沿用现有无 panic 队列 flush 合同。

FIFO 每个 token 为 `{left[15:0],right[15:0]}`，左右原子跨域，一帧取一次，标准 I2S 每声道 32-bit 时隙，16-bit PCM 在前，其余补零。`STEREO_ENABLE=0` 为显式旧双单声道旁路，便于逐位回归；正式板级默认启用。

`midi_voice_top`、`pad_voice_top` 透传同域位置及 ITD 开关。板级提供默认居中与可选自动往返扫动，用于 DAC/音箱试听，不占用菜单摇杆。

## 硬件与验证边界

Pebble V2 通过 USB-C 供电，通过 3.5 mm 接收双声道模拟音频。现已接入板载PT8211/耳放/J29，外部标准I2S与板载LSBJ共享同一对样本；现有 MAX98357A 喇叭功率输出不可直接接 AUX。具体 DAC 的 MCLK、格式和接线需按实际模块确认。当前板级音频时钟为 12.5 MHz/256=48.828125 kHz，4 样本为 81.92 us；48 kHz 系数资源原有速度偏差及整板物理时序问题不由此功能解决。

验证要求：33 档和 Q4 过渡位置整数参考对拍、正负极值/低电平/随机样本、ITD 方向和分数抽头、静音推进及历史清理、开关 ITD、超范围钳位、连续异步 I2S 左右解码、双演奏入口集成、旧音频回归、Gowin 独立综合确认乘法器/DSP 为零。实际命令与结果见下节。
