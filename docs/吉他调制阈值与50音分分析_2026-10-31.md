# 吉他调制阈值与 50 音分分析（2026-10-31）

本次完成力度起点同步，保持现有调制上限与前四模态限制。没有修改 Flash 镜像，没有把 50 音分配置写入生产路径。

## 已实现的修改

`voice_router.PAD_NOTE_ON_TH` 经 `mod_router` 传入 `modulation0`。零调制点使用同一阈值，不再硬编码 242。已有的 voice_router 默认 102/13 阈值修改予以保留；板级 instrument_system 覆盖的 64/48 也会自动生效。MIDI velocity 仍不参与此压力调音。

```
TH = PAD_NOTE_ON_TH
MAX = MAX_LAMBDA_Q30 = 37580959    // 保留原上限，约 0.035
FULL = 230
STEP = round(MAX / (FULL - TH))
lambda_q30 = MAX                       fmap >= 230
             0                         fmap <= TH
             STEP * (fmap - TH)         其余
```

这是力度对频率比例增量 lambda 的线性映射。固定整数步长四舍五入，230 起使用精确 MAX，之后一直饱和；不能把它等同于音分严格线性。阈值 102 的 STEP=293601，64 的 STEP=226391。TH>=230 的兼容入口没有线性区间，230起阶跃到上限（避免 MIDI 等旧默认入口因零分母而失效）；正常压力入口应使用 TH<230。note_on 判定为 `fmap > TH`，因此正常压力入口首个有效力度 TH+1 有一个步长的音偏。2026-10-31 按用户要求将满幅压力从255改为230，保留前四模态与原lambda上限。

lambda 在接受 start 的时钟锁存；一次任务的全部字段/模态共用该快照。此前 fmap 在任务中改变会让不同字段采用不同 lambda，本次已修正。仍从独立基值计算，维持幂等。

## 50 音分的比例与量化

```
alpha = f_new/f_old = 2^(50/1200) = 1.0293022366...
lambda_max = alpha - 1 = 0.0293022366...
Q30(lambda_max) = 31463037
```

旧 MAX 对应约 59.5569 音分。若只要求压力对频率比例线性，替换 MAX 即可改变端点；若要压力对音分严格线性，则应使用 `lambda(u)=2^(50*u/1200)-1`（u 为归一化力度），可用小查表。直接线性 lambda 时中点音偏约 25.1805 音分，偏离音分线性约 0.1805 音分。

## 量化后的静态极点扫描

脚本：`sim/analyze_modulation0.py`。输入为仓库 `rtl/router/tools/guitar_flash.bin` 的真实大端 Q 格式记录，以及 `sythsound/guitar_param.txt` 的 MIDI40..79 参数目录。前者为 16 音布局，后者为 40 音目录；不是对板上 Flash 的读回结果。

精确复现 RTL 的乘法截断、a21 先右移再取负，不能用未量化浮点系数代替。每模态检查谱半径，以及 Jury 三个条件：

```
t = a11 + a22
d = a11*a22 - a12*a21
1-d > 0, 1-t+d > 0, 1+t+d > 0
```

## clamp 能解决什么

1. **限制 lambda：有效，但只能在已经验证稳定的范围内。** 当前前四模态可以将上限缩到约 50 音分。若要全 20 模态共用同一个保守上限，目录扫描得到的一个可用候选是 Q30=7557269，名义约 12.142 音分。它来自稳定边界搜索后再留 2% 余量，已检查三个阈值的全部实际压力码；这是候选值，既不是精确最大值，也不证明任意连续变化都稳定。
2. **把 a11/a12/a21/a22 各自 clamp 到 [-1,1]：不能保证稳定。** 稳定性取决于整组矩阵的 trace/determinant，所有元素都小于 1 仍可能有极点大于 1。a11>1 也不是普遍适用的不稳定判据。
3. **把 q/v 或输出硬限幅：只限制爆音幅度，不能消除自激。** 可能形成持续饱和/极限环，不能作为调制稳定方案。
4. **对整组系数做稳定域投影：可以作为方案，但需要计算/验证。** 对具有共轭复极点的候选矩阵 A，`rho=sqrt(det(A))`。若超出目标半径 r，可令 `A_new=(r/rho)*A`，同时缩放四个递推系数，保持极点角度，压回极点半径。重新量化后必须再检查 Jury，并留足余量；实极点情况另行处理。wo 不决定递推极点。在线求根/除法成本较高，适合先离线生成按音符/模态/力度的稳定表或分段参数，不能只 clamp 一个字段。

一阶展开为什么会向外漂移：以简化的阻尼旋转矩阵为例，令 theta 为原每采样相位，delta=lambda*theta：

```
A_linear = r * [[cos(theta)-delta*sin(theta), sin(theta)+delta*cos(theta)],
                [-sin(theta)-delta*cos(theta), cos(theta)-delta*sin(theta)]]
rho(A_linear) = r * sqrt(1+delta^2)
```

一阶切线引入二阶半径增长；theta 较大的高模态先越过单位圆。只限制元素数值没有消除这个机制。

## 若要求全音色稳定达到 50 音分

建议改为生成固定目标半径、目标相位的系数，再经量化稳定性检查，不再直接扩大一阶线性矩阵的适用范围。可选离线稳定投影表，或重新组织为归一化阻尼旋转状态：`z[n+1]=r*R(theta_new)*z[n]+b*x[n]`。后者在同一固定状态基底且精确运算下，每一步的范数收缩为 r，任意变化的相位也不会引入切线增益；但需要重做状态/输入/输出系数，不能直接塞入当前参数表。RTL 定点舍入与有限幅度也仍须验证。

动态调制不能只检查冻结系数的极点。当前各模态逐条写回，没有整个声部的帧边界原子提交；本次锁存 lambda 消除了任务内压力撕裂，但未增加双缓冲。正式扩大音偏/模态数前，应做全模态同帧提交、压力变化速率限制（保持稳态映射线性），再验证最坏跳变、往返扫频和持续音的状态能量。速率限制本身也不构成稳定性证明。本次未宣称任意压力序列稳定，未做布局布线时序签核。
