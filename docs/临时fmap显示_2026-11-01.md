# 临时 fmap 显示

搜索 `TEMP_FMAP_DISPLAY_20261101` 定位模块和接入点。

- 独立模块：`rtl/platform/tang_mega_138k_pro/temporary_fmap_display.sv`。
- 接入：同目录 `instrument_system.sv` 的最终 RGB 输出处，文件列表
  `sources.f` 增加一行模块路径。
- 显示 `pad.fmap.raw` 的 16 个原始无符号字节，三位十进制 000–255。
  不是经过负数屏蔽、乘四和饱和处理的 `force_map`。
- 固定面板位于逻辑坐标 x=320–575、y=48–175，每格 64×32 像素。
  第一行 slot 0、1、2、3，随后 4–7、8–11、12–15。
  深蓝背景、黄色数字，复用现有屏幕旋转后的逻辑坐标。
- 复用 `sidebar_mailbox` 传输整包快照，仅在帧末接受；一帧内数字保持。
  数字由七段笔画生成，不增加字体 ROM。叠加层延迟四拍，与原 UI RGB/DE 对齐。
  面板外透传原图，原 LCD 时钟和 DE 路径不变。

撤销：删除独立模块和 `sources.f` 中对应路径，删除标记的接入块，
将 `u_ui` 的 RGB 输出恢复直接连接 `lcd_r/lcd_g/lcd_b`。

验证产物位于 `build/fmap_display_20261101/`：独立模块覆盖 256 个数值、
异步快照、slot 顺序、帧内稳定、像素延迟及透传；完整工程编译和
800×480 两帧 LCD 时序检查通过。`fmap_panel.png` 是 RTL 仿真像素预览，
使用 0、17、34……255 作为演示值。

按后续“现在烧录”要求，已完成综合、布局布线和时序验收：setup 最差裕量
0.740 ns，hold 最差裕量 0.181 ns，所有检查无违例。110 个构建输入哈希一致。
SRAM 下载 100% 并返回 Finished；独立回读 ID 0x0001081B、User Code
0x00002C5D、Status Code 0x00026230，与下载结果一致。
当前版本包含先前临时输出乘二及居中单位增益。未写入非易失 Flash，断电后
SRAM 配置失效。记录见同一产物目录中的 `download-result.json` 和
`implementation/acceptance.json`；实际屏幕显示待实板观察确认。
