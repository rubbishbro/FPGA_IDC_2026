## 维护约定

同一主题只维护一份正文，日期写入章节，不再按对话轮次新建文件。参数归音频设计，实测/仿真/烧录及失败过程归调试记录，测试步骤归上板测试；其它文档链接引用。已归并的旧正文删除，不留跳转壳；旧版本可在Git历史查看。机器可读历史证据与实验来源记录保留原样。
