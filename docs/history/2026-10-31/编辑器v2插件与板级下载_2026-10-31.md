# 编辑器 v2 插件与板级下载（2026-10-31）

编辑器新增可选的 v2 串口适配层，保留 v1 有线 UART。连接区可查看握手阶段、会话编号和演奏代次，查询会话状态，并发送混响配置等待真实结果。显式链路测试包括单帧坏 CRC 和停止心跳。

## 传输和恢复

Web Serial 打开不等于连接完成；只有 READY 后才允许演奏。MIDI 在实际写入前分配序号，取消尚未发送的消息不产生序号空洞；PING 在调度时生成，携带实际已发送的进度。配置采用单请求等待，心跳可继续。设备要求重新同步时暂停走带、取消旧代次消息、将未决配置标为结果未知；收到 PLAYBACK_READY 后以新代次重建当前踏板及音符状态。

插件通过串口工作，未新增浏览器经典蓝牙 SPP 后端。板载 USB UART 仍为 v1；验证 v2 需连接蓝牙 UART 对应管脚的 USB-TTL，或系统实际暴露的 HC-05 串口。会话状态查询不包含音色、通道或音频后端就绪情况。

## 构建和下载证据

本轮使用 Gowin IDE `/home/rubbishbro/gowin/IDE/bin/gw_sh`，独立构建目录为 `build/editor_v2_board/implementation`。设置 `BOARD_PNR=1 BOARD_BT_PROTOCOL_V2=1`，生成仅该构建使用的顶层参数变体，包含板级音量增加、屏幕旋转和摇杆方向修改。输入快照 `build/editor_v2_board/input_sha256.json` 包含 106 项生产输入。

JTAG 识别为 USB Debugger A（FT2232），目标 GW5AST-138B，实读 ID `0x0001081B`。厂商 CLI 需使用 `--cable-index 4 --channel 0`；`--cable` 单独传别名时不能可靠覆盖类型。内核 `ftdi_sio` 占用 JTAG 接口时，使用 libusb 临时 detach 接口 0，操作后在 finally 中 attach 恢复，UART 接口 1 不变。记录在构建目录中，不修改持久 udev 配置。

本轮使用 SRAM 下载，未擦除或写入 Flash 音色资源；最终时序与下载均通过。
