复现（仓库根目录，需 numpy、iverilog/vvp）：

```bash
python python/modal_sim/eng1_cosim.py --mode intended
# cases=66 errors=3 / RESULT: FAIL
```

仿真 TB 的 `$finish` 不一定让 vvp 返回非零，必须检查 `RESULT`；Python 对拍入口会将不匹配转为失败。完整命令和工具路径见 [sim 说明](../sim/README.md)。

## 2. 原 F 编号的当前状态

“源码已调整”仅表示原错误结构已改变，不等于该功能完成板级验收。

| 原编号 | 当前源码 | 仍需验证 |
|---|---|---|
| F01/F02 选表/槽步长 | loader/router 均使用 `{sel,slot,mode}` 和 RAM padding `NMP`；Flash 保持紧凑逐 slot 表 | 48/64/80 模态的全部 slot、两张表及实际 loader 写口；不能用音乐 TB 的直接灌 RAM 证明 |
| F03/F04 多槽激励/采样索引 | 批次激励 RAM 已移除；一次作业一个采样，整张 xmap 存入 x_q，再按 A/B 槽读取 | 多键激励、起音/松键和两 bank 独立性；旧 xw_i/fidx 复现已不适用 |
| F05 eng1 反馈/清零 | 乘法使用当前同步返回的 `st_q/st_qdot`，全模态应用 st_zero；数量寄存器已扩宽 | intended 对拍非零模态 63 项一致；空作业仍失败，另列 F12 |
| F06 调制重复启动 | mod_start 默认每拍清零，复位初始化，按 pending 位图后台发单拍请求，并与加载互斥 | 队列排空、公平性、重触发/加载中止，不能宣称持音持续调制已完成 |
| F07 吞吐 | 双 bank 并行且调制不再在采样 FSM 中阻塞；旧 3922/36276 拍不是当前测量 | 28日Questa声明兼容副本已测eng1输出间隔4166拍，超2083拍预算；其余规模/切换与实际DAC仍待验 |
| F08 包络变负 | 默认 attack 已按 signed 越界钳位，并有输出保护；旧 0x80000000 负峰结构已改 | 任意开放参数的合法范围、重触发、release；不能由默认常量推出全参数正确 |
| F09 混响乘积 | 干湿/抽头中间量已扩到 69 bit，加和有饱和；反馈仍直接在 64 bit 目标中乘/移位 | 28日补测已确认NONE输入2^42输出0；继续关闭完整96bit乘积/缩放、反馈及饱和边界 |
| F10 预设切换读旧 RAM | reverb_router 已在 preset 改变时给 comb_clr | NONE→HALL 等切换、预置非零 RAM、流水参数一致性与尾音策略 |
| F11 事件节拍错位 | ADSR 起音历史按 clk_en 更新；激励 clear 有挂起；router note/dead 积累到作业头 | 帧间短事件、重触发、换音色/reload 与各模块清理一致性 |

其它旧条目也有进展：模态数由 `n_modes_of(inst)` 内部选择并锁存/限幅；`load_err` 在 voice_router 引出；SCK_DIV 已实现相位内分频，BLANK_WAIT 计数位宽已收敛。`pad_voice_top` 尚将 `load_err()` 留空，上层无法仅凭 ready/done 判断加载成功。

## 3. 当前 router 风险与集成缺口

| 范围 | 当前事实 | 后续验收 |
|---|---|---|
| bank B | R7仍为旧真实音色场景记录；28日Questa声明兼容副本已有64次不同状态比较通过，未覆盖全部起音/释放 | 仅按高半区槽、A/B 同时/交替、不同初值和音高，比较状态与输出 |
| 实际 Flash | 现 loader 的头部使用 0x6B，地址以 4 bit/拍发送；音乐 TB 绕过 SPI，镜像自检只检查格式 | 对照实际 Flash 型号的命令/地址线宽、dummy、QE、采样相位与分频，真实行为模型及真片读取；不能因工具自检通过就声称物理协议正确 |
| 参数一致性 | voice_router 默认 64 模态，pad_voice_top 默认 48；钢琴镜像默认 16×64，Flash 表基址依赖 N_MODES | 最终顶层、打包器、Flash 烧录和实际模态数统一；否则后续槽会错读镜像 |
| 调制提交 | 当前只在起音置请求，后台逐模态写系数；28日隔离夹具已见7个声部帧混合版本，不等于已测可闻爆音 | 持音更新节拍、同地址读写语义、跨模态一致性、开关/深度消费者和稳定性 |
| 配置等待期间 | 28日Questa兼容副本确认：挂起钢琴→吉他时ready=0但active_nm已为20，旧表应保持64 | 跨不同模态数音色、按住键申请切换，核对旧表/旧 inst/模态数的一致性 |
| debug | ns_rd_* 返回缓存的最近状态字，不能任意寻址 RAM | 明确工具展示语义，勿据地址输入推断真实地址读回 |
| 混音/输出 | 64 位跨声部加法仍可能回绕；tb_music 的削波统计不拦 PASS，WAV 导出按峰值归一化 | 16 键最大力度、正常幅度定标、饱和、真实 PCM 削波/欠载，不能靠 WAV 响度证明余量 |
