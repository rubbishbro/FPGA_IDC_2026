# 运行时声像配置

配置编号 `0x0102`，稳定索引 21；值为整数 0..32，0=左、16=中、32=右，步长 1。
LCD 的“效果 → 声像”可以编辑并确认应用。默认居中；板级 `STEREO_PAN` 现在仅决定复位初值，不再锁定运行时位置。复位会丢失运行时设置。

路径：sidebar_ctrl → control_loop → config_dispatch → instrument_system 的配置后端 → runtime_pan → spatial_pan → midi_voice_top → stereo_spatializer。
后端接收合法请求时提交目标位置并返回 CFG_OK，dispatch 随后发布 active_values[21]；超范围返回 CFG_OUT_OF_RANGE，保持原值。成功回复表示目标位置已提交，不表示平滑移动已经完成。底层空间化器按音频帧逐步趋近目标。

配置事务使用现有 cfg_request_t 的 tag/id/value 与 cfg_response_t 的 tag/id/result/applied_value。
sidebar_system 的 ext_cfg_request 也可使用该编号；当前板级 UART 桥只翻译既有命令，尚未提供通用 cfg ID 写入命令，因此本次不增加串口协议或 MIDI CC10。

STEREO_ENABLE=0 或 STEREO_AUTO_SWEEP=1 时，能力位不开放声像配置，请求返回不支持；自动扫描继续使用原扫描位置。

这是一维整体声像：单声道合成混音通过左右增益差（ILD）和可选微小时延差（ITD）生成立体声输出。没有距离、前后、上下或独立声部位置；MIDI 通道编号与此参数无关。

验证入口：`python sim/run_pan_runtime.py`，需要 Verilator 和 C++ 工具链。
测试从 UI 配置请求边界注入事务，覆盖非居中复位初值、0/16/32、非法 -1/33，以及提交快照和音频输入连接；不替代按键交互、DAC 波形、综合时序或实板听音验证。

本轮直接使用工作区源码运行 Verilator 5.048 配置链路测试通过：非居中初值8、0/16/32、非法-1/33、已提交快照与音频连线。此前小号模块语法错误已修正，不再需要测试副本替换。完整UI回归仍在既有外部配置反压场景 system_7 watchdog，不能宣称UI全通过。声像寄存器和配置快照使用固定异步复位，复位释放后同步加载板级初值；初始化完成前不接收请求，避免Gowin对动态异步初值的DI0004告警。整板综合和PnR在 build/ui_pan_pnr_20261102/source_v2 输入快照上执行，结果以build_v2.log和implementation_v2/acceptance.json为准。未烧录。
