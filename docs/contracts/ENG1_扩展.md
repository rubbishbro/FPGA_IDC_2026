> 合并自 ENG1 鼓噪声（历史原文见 Git）、ENG1 aftertouch（历史原文见 Git） 与 mod1 逐声部调制预算（历史原文见 Git）（2026-11-02/03）。三份文档都落在同一套 ENG1/mod1 数据通路上：噪声是鼓件资源合同，aftertouch 是逐声部压力调音，预算报告是两者的时序/资源证据。

## 一、鼓噪声数据合同

2026-11-03用户确认主体采用零状态单冲激ABC、噪声采用拟合单低通/双低通差分的正式方法；共享生产入口为 `python_monotor/modal_sim/drum_coefficients.py`，不再将任意相位seed装载作为当前选定方案。该方法已完成六件完整采样RTL核对，鼓组后续已正式接入生产资源与生命周期，并通过用户整机功能验收，见[试听与当前增益](../reports/2026-11-03_鼓镲对照试听与当前增益.md)。

噪声开关由Flash记录的LFSR seed决定：seed=0禁用，seed≠0启用。
不新增enable、trigger、velocity等端口，ENG1保持原接口。
本合同替代此前的显式开关/tag提案；生产镜像与整机接入见[鼓组正式接入](../reports/2026-11-03_鼓组正式Flash与ADSR接入.md)，当前验收见[状态页](../status.md)。

### 槽布局与Flash位置

鼓件的手机配置与MIDI乐谱外部编号统一采用GM Note号：36/38/45/42/59/49，
依次查表转换为内部资源索引0/1/2/3/4/5；外部不发送0～5。
每件鼓起点为鼓组区起点加`drum_index*0x1000`，下文seed偏移再相对于该鼓件起点计算。
完整映射与配置范围见[通信协议约定§3.2.2](./通信协议约定.md#322-鼓组统一外部编号与内部索引2026-11-03冻结)。

`n_modes<=48`全部按ABC计算；`n_modes>48`时，前48槽为ABC，其后每两槽为噪声支路。
因此新布局的50/52/64槽不表示50/52/64个普通ABC模态。
当前普通ENG1资源仍使用48个有效模态，行为保持不变。
`router_pkg::n_modes_of(INST_DRUMS)`固定为52（48模态＋两条噪声支路），
不随seed开关变化；物理RAM深度仍为64。调用者也可固定用50槽表达一条支路。

每条支路两条记录，主槽48/50，扩展槽49/51。资源每个模态记录64字节：
相对于该鼓件系数资源起点，第一条seed在`0xC00`（48×64），第二条在`0xC80`（50×64）。
这是鼓件资源内偏移，不是绝对Flash地址；还须加镜像基址、乐器区及鼓件偏移。

| 主记录字段 | 记录内偏移 | 含义 |
| --- | --- | --- |
| a11 | +0 | LFSR seed，原始无符号32位；0关闭、非0启用 |
| a12 | +4 | 包络初值，UQ24，范围0..1 |
| a21 | +8 | 每采样衰减系数，UQ24，范围0..1 |
| a22 | +12 | 下截止一阶低通alpha，UQ24 |
| gq | +16 | 上截止一阶低通alpha，UQ24；0≤下≤上≤1 |
| gv | +20 | 非负增益，signed32 Q16 |
| wo | +24 | 保留，不作为tag或enable |

扩展槽的co字段保留，无需写入tag。主槽q/v保存LFSR/包络，
扩展槽q/v保存两个低通历史状态（signed32 Q24）。LFSR按位图读写，不走有符号饱和。
Flash加载仍使用原loader：读入co后由ENG1按地址解释，不需新增协议或引脚。

只将某主槽seed写0即可关闭对应支路；整条记录全0也可。另一条支路不受影响。
非零seed还须配合有效的包络、滤波与增益参数；无效参数按静音清状态处理。
仅烧录后要重新加载资源/重启，未重载的片内系数不会随Flash自动变化。

### 沿用原接口起音和清理

- `st_zero`始终优先，清状态并静音，不因正激励而同时重启。
- 清理后，运行LFSR为0且现有`x_data>0`时自动起音：装载seed和初始包络×min(x_data,1.0 Q24)，清滤波历史。
- 无正激励时，即使Flash seed非0也不自动发声；首帧激励为0时可等待后续正激励。
- 运行后`x_data`变化不重复触发，不持续改变尾音音量；下一次击打经现有`st_zero`重新准备。
- 维护清理/重载期间上层须使激励为0，否则清理后的正激励仍表示一次新击打。
- seed=0、非法参数、未收到正激励的零运行态会直接输出0并清两槽；不把LFSR=0映射为持续−1。
- 重载参数不会直接改状态RAM，须先清理旧范围，再演奏或缩小`n_modes`。
- 单独末尾残槽清零且不发声，不跨有效范围访问。

这一无新端口约定采用现有激励的正幅度作为起音力度，不能独立接收另一份velocity。
生产鼓前端采用零状态单冲激ABC主体；Note-Off进入ADSR Release，包络结束后清理并回收声部，已完成整机联调验收。

## 二、aftertouch 逐声部压力调音

`voice_router → mod_router → modulation1` 负责持续音色的逐声部 PAD 压力调音。
当前启用范围由 `uses_mod1()` 指定：长笛、小号、大提琴、小提琴、双簧管、班卓、曼陀铃、吉他 2。

- 零点沿用 `PAD_NOTE_ON_TH`，当前默认 102。
- 音偏：`max(0, pressure - PAD_NOTE_ON_TH) × 0.75` 音分。
- 默认力度 102 / 152 / 202 / 255 对应 0 / 37.5 / 75 / 114.75 音分。
- 内部音分为 Q8，每档精确为 192；255 对应 114.75 音分。2026-11-04 将单位力度响应提高 25%。
- 按住时随压力升降，最低为 0；松键尾音保持最后提交的音偏。
- 无额外 slew 或 LFO。2026-11-03起改为与mod0一致的逐声部start/busy/done作业，不再每96采样整表更新。
- 一次作业只锁存所选声部的压力、门控、来源和使能；作业期间的新压力留待后续更新。
- P1T1 基值不变；由音分换算 Q24 频率比，再计算并限幅 `a1_base + K × delta`。
- `MOD1_MODES_PER_JOB` 限制每声部更新的**前N个模态**，不是轮转分块；其余模态保留名义系数。当前暂定6；TODO：听感还需要验证。
- 直接写既有`ca_a12_a/b`；独立`pitch_a12_a/b`已删除。引擎不读取调制参数表，参数表无需拆分，基值/斜率始终不变。
- 当前帧该声部引擎完成后才能更新；以最近实测采样间隔检查剩余窗口，作业完成并发布该声部频率比后才进入下一采样快照。窗口不足时延后任务，不阻塞音频。
- 轮询加服务轮次标记保证大N时后面的声部不会饿死。现为持续乐器每组退休登记一次请求，包含MIDI禁用压力时的名义系数恢复。
- MIDI velocity 不作为持续压力；原 wheel/bend 请求明确返回 rejected，不产生音偏。
- PAD/MIDI 模式切换和声部归属变化通过提交屏障处理；清理中断半成品作业。

Flash P1T1 与 ratio 表格式不变。旧 sine/depth 表仍占据镜像原位置，但本模块不再存储或使用这些表。
本次不扩大音色范围，也不改变 ENG0 的 modulation0 映射。

## 附录：mod1 逐声部调制预算

已将mod1改为与mod0一致的逐声部start/busy/done任务。`MOD1_MODES_PER_JOB` 控制每次更新的前N个模态；不是轮转分块，也不是一次处理N个声部。其余模态保持名义系数。扫描时默认值为4；依据本次结果，当前暂定6，TODO：听感还需要验证。

调制器读取原P1T1参数表，写回既有ca_a12_a/b。pitch_a12_a/b已删除，没有新开系数RAM，参数表不拆分且引擎不读参数表。保留不可变基值、斜率、上下界和tag。旧pitch_bank观测口恒为0，不再选择RAM或全局翻转。

安全窗口：本帧该声部引擎退休后才能启动；以最近采样间隔核对剩余周期，给任务预留6N+20拍（包括调度余量），确保写回及频率比提交在下一帧激励快照前完成。窗口不足只延后调制，不等待或暂停音频。轮询加服务轮次标记避免后部声部饿死。当前持续乐器每组退休都会登记请求，包括MIDI关闭压力调制时的名义系数重建。

### 如何理解“藏在引擎计算中”

1. **逐组不积压：上限3。** 对前7组，在下一组引擎退休时，上一组的两个声部调制均已完成；N=1/2/3的相邻组迟到检查均为0，N>=4开始积压。
2. **严格全部藏在最后一组引擎结束之前：本调度不存在这样的N。** 最后一组的请求本来就在它自己退休后产生。N=3仍有最大55拍（1.10微秒）的末尾调制工作，N=4为109拍。它利用帧内余量，不延迟音频输出。
3. **每帧16声部都更新且音频不等待：两种路径共同上限6。** 小提琴可到8；小号从7开始无法每帧服务全部声部。上限6单声部43拍。
4. **大N也不会因调制阻塞音频，但更新频率下降。** N=48时，小提琴每帧1–3声部、最大9216拍（184.32微秒）更新间隔；小号每帧1–2声部、最大13312拍（266.24微秒）。轮次服务保证没有声部长期饿死。

这些界限只针对上述固定采样节拍、资源、声部数和当前实现。它们是周期级仿真结果，不是物理Fmax，也不是减少高模态调制后的听感验收。N限制会改变音色内不同模态的音高关系，需另行试听。
