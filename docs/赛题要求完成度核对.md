## 1. 先说结论与判定口径

**合成、逐声部处理和独立可视化都有实质进展，但基础要求仍不能整体勾“完成”。**新增 `rtl/router/voice_router.sv` 已接入完整矩阵输入接口、ADSR／动态包络、激励、调制、混音、腔体和混响；不能再笼统写成“只有包络乘法器／调制未接”。但该路径有尚未修复的地址、激励、状态、包络和吞吐问题，完整演奏输入、持音实时变调、I2S/DAC、四路独立可闻声部与端到端延迟仍未验收。

“完成”必须注明层级：

- **模块已实现／已测**：有 RTL 与对应仿真，不保证正式顶层已经使用，也不保证实板达标。
- **部分实现／待集成或验收**：有架构或可复用模块，但题目要求的整条功能链缺失，不能笼统说“没做过”，也不能说“已完成”。
- **已设计、未实现**：有方案、流程或协议草案，尚无可工作的实现。
- **未细设计**：只有模块名、目标、历史概念或题目提及，未见当前可执行的接口／状态机／映射／验收方案；不是断言作者线下从未考虑。
- **自主增加／超出最低要求**：可以有产品价值，但不能替代基础项；也不代表天然获得额外分数。

### 2.1 新 router 已知问题：不是只差接线

以下均已对照当前源码，详细位置、原因和建议见 [ROUTER_AUTHOR_HANDOFF.md](ROUTER_AUTHOR_HANDOFF.md)。**该交接明确说明此前修复已撤销；本轮未修改 RTL，不能把建议当作已修复。**其中数值复现／周期数引用交接记录，不冒充本轮新测量。

| 问题 | 对完成度的影响 |
|---|---|
| **F01／F02：表边界与槽地址契约不一致** | loader 用 `slot*N_MODES+mode`、参数表基址 `SLOTS*N_MODES`；router 用高位选表和拼接地址。48／80 模态时会错表、错槽或越界，loader 单测 PASS 不能保证整机装载正确 |
| **F03／F04：激励写槽提前结束，读地址遗漏 fidx** | 默认 16 槽时只写第 0 槽；后续采样仍读第 0 个位置，阻碍独立多声部／持续音验收 |
| **F05：eng1 反馈使用上一模态状态，st_zero 未覆盖所有模态** | 单个 G-only 黄金用例通过不代表多模态递推正确；需补非零反馈、不同模态初值和连续作业测试 |
| **F06／F11：调制重复启动、采样事件可能丢失** | 起音／重触发／切音色的控制语义不稳；调制只在起音触发也不足以实现持音实时表情 |
| **F08：ADSR attack 未钳位正上限** | 默认步长第 128 次 attack 更新可到 `0x80000000`，形成负包络；不能宣称包络已验收 |
| **F09／F10：混响乘积先截断、切预设可能读未初始化 RAM** | 小幅度模块测试 PASS 不足以覆盖正常量纲音频；需完整乘积位宽、缩放／饱和及切换有效性测试 |
| **F07：eng1／调制超过每采样预算** | 交接记录 16×48 的 eng1 相邻输出 3922 拍、吉他 16 键起音首输出 36276 拍；100 MHz／48 kHz 约 2083 拍预算不能满足。E2 的既有 1474 拍记录不能推广到所有路径；本项是吞吐问题，不直接等于总延迟超 10 ms |

另外：loader 的 `err` 未接入顶层错误策略，真实 Flash／音频管脚约束未完成；应与数据通路问题一起收口。

|---|---|---|
| 多路不同频率同时输出、看到对应独立谱峰 | 递推核、独立 FFT 三音 demo、1–10 kHz 扫频源及其仿真 | 可选择数量／频率的**正式现场测试模式**，走主合成／DAC 同一通路；可视化内部正弦／扫频不能代替主引擎证明 |
| 独立振荡器／模态数及吞吐 | voice／mode/lane 结构、E2 周期记录、新 router 超预算问题定位 | 修复后统计同时活跃且可闻数量、独立状态／控制、谱峰、实际 DAC 采样率及 `数量×采样率`；逐路径覆盖首帧／稳态／批边界 |
| 纯硬件生成，没有预录播放 | 当前算法源码与系数 ROM | 最终源清单、现场演奏改变实时结果的演示、排除 PCM 播放通路的证据 |
| 延迟指标可信 | 探针报告、可用示波器测法的原则性讨论 | 明确输入／输出标记、阈值／起止定义、重复次数、最坏值和抖动结果；测法与判定口径需先冻结 |

测试模式及证明材料是题目明确提到的事项，不应全部当成最后做展示时才补的包装工作。

## 5. 按用户关心的四类归纳

### A. 已经做出来的部分（不是整机全通过）

- ABC／E2 定点核心、系数／状态存储、loader 和混音；新 router 已有 Flash 协议加载模块及镜像工具。
- 新 router 的 16 路压力门控、脉冲／脉冲串激励、ADSR（含 release）／动态包络、调制写回及逐声部包络乘法。**实现不等于正确性已收口。**
- 新 router 的 5 段腔体、四梳状混响和预设入口；旧 core 仍保留自己的后级版本，不混用模块接口。
- 独立 FPGA 频谱、真实波形、FALL 历史曲线、UI／双按键／扫频；本轮 14 项可视化测试通过。
- 本轮 router 4 项模块测试通过；旧音频链有历史实现／出声记录，压力／摇杆／LED 有旧驱动可复用。

### B. 已设计或已有模块，但尚未实现／集成／验收

- 修复新 router 的装载／槽地址／激励／反馈／包络／混响问题，恢复旧核心回归入口或明确替代测试路径。
- 真实驱动→键位／音高／力度→至少四路独立声部→新 I2S/DAC 的完整板级演奏链；Flash 真片读取和错误处理。
- 将已接入的起音调制扩展为安全的持音实时变调，明确包络参数／重触发语义；不能再把这两项都归为“未写模块”。
- FPGA 频谱／波形／FALL 接主引擎 PCM 和跨域 FIFO；独立可视化编译已不是当前阻塞。
- 电脑 UART 协议／MIDI 工作台／音频回传草案；手机简易控制的产品规划。
- 四复音、满载周期、≤10 ms／≤5 ms 都缺最终证据，不能只算“写完代码”。

### C. 超出题目最低功能清单的自主设计

| 自主设计 | 与题目的关系 | 对当前排期的含义（建议，不是删除决定） |
|---|---|---|
| 完整电脑 MIDI 编辑器、多轨卷帘、量化／撤销等 | 题目没有要求做一个编辑／编曲软件 | 可先做最小测试／控制面板，完整编辑器不能替代演奏闭环 |
| WebGL 前端、WASM 本地试听／模型 WAV 导出、桌面打包 | 属于产品实现与分发方式，不是 FPGA 题目指标 | 不应比硬件端变调／包络／出声更优先 |
| 频率—增益曲线、逐模态音色塑形 | 用户音色设计附加能力，不是原文明列的基础必做；也不等于实时变调 | 可作特色，但要与 DSP 安全更新和实际听感一同验证 |
| A/B/C/E2 多种计算路径并存 | 题目允许任选合规算法，不强制两套不同递推核 | 是自选实现复杂度；若服务 ≥2 音色／并行模态可有价值，但核数量本身不是额外必做 |
| 频谱之外的 FALL 历史曲线、精细页面和跨端预设协同 | 题目鼓励可视化／联动，但没有强制这些具体形式；FALL／页面已有独立实现 | 属于展示／产品体验深化，不能替代主合成器可视化联机或 LED 曲目指引 |

**不应误归到题外：**蓝牙手机联动、录音回传、实时频谱、混响，原文都已列为拓展方向；16 槽高于基础 4，但仍是题内复音方向，不是独立的题外创新。

### D. 提过名字或目标，但还没有细设计的地方

优先补的是：

1. 持音变调的控制节拍、后台计算／系数安全提交、状态连续与音准方案；明确已有包络的外部参数控制／重触发／换音色语义，**不是重新把发生器列为未实现**。
2. pad→不同音高的系数／调制表契约，以及三维演奏映射；特别是摇杆／压力如何独立驱动滑音、颤音等参数。
3. 脱机 LED 曲目指引的数据、节拍和显示控制。
4. 当前正式现场测试模式、独立可闻模态统计和延迟验收方案。
5. 在线曲谱下载、可保存／可下发的自定义键位、手机端硬件录音回传闭环。

独立 delay／chorus、李萨如可列为未选择或低优先级候选，不因未细设计就判基础不合格；真实波形已有独立实现，待接主链。32 voice 是 E1 的可选路线之一，当前未选它也不是必须补的漏洞。

## 6. 建议的先后：先基础闭环，再选拓展，最后产品增强

1. **P0：先收口当前正确性和回归入口**：统一新 router 的表／槽地址契约，修复激励、eng1 反馈、包络上限、事件／调制握手及混响位宽／初始化问题；补能覆盖这些缺陷的回归。明确采用哪条主链，不混用旧 core 与新 router 的证据。
2. **P0：冻结演奏语义和采样预算**：键位→音高、两个独立维度、至少四复音、可控包络、持音实时变调；调制移出硬实时临界路径或采用已验证的替代调度，分别测首帧／稳态／批边界，先确认承诺的复音／模态规模。
3. **P0：新音频板级闭环**：真实驱动／Flash→合成→后级→PCM→FIFO→I2S→DAC，完成连续播放／复音／峰值与 ≤10 ms 验收。可先选一条可靠音色路径，不强制全部 class 同时齐全。
4. **P1：选定少数拓展闭环**：≥2 真实音色切换、修复后的混响、已有可视化 demo 接主引擎；并行模态与吞吐用正式测试模式证明。≤5 ms 先测再承诺。
5. **P1/P2：按选择补 LED 曲目指引、三维表情或 BLE 简易控制**；最后扩展电脑 MIDI 编辑器、频率曲线、WASM／多轨／跨端预设。产品增强不能替代基础交付。

不提供“已完成百分之多少”：缺少官方细分权重，且模块通过、历史板级通过和当前整机达标不是同一分母。
