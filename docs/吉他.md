## 源录音与自然尾音

目的：用户认为吉他和钢琴相似，检查是否只是release短、系数失真或源录音质量问题。
本轮停止继续扫脉冲宽度；未更改生产RTL或已确认钢琴参数，未将新吉他ADSR视为生产默认。

### 事实

- guitar和piano来源不同：吉他为本地guitar_A4_very-long_forte_normal.mp3，钢琴为UprightPian/samples/A4vH.flac。
- 同为MIDI69/forte，吉他有20个有效模态，钢琴13个；G/a1/a2数组不同，并未混用表。
- 当前吉他A4模态振幅时间常数约0.0175–0.2923秒，中位约0.0797秒；钢琴约0.1137–0.3936秒，中位约0.2556秒。
- 旧参数构建器对吉他A4使用gamma_scale=1.8。基频提取gamma约1.900/s，乘校准后约3.421/s，即tau约0.292s。
- 从原始吉他录音独立投影基频、50ms步进/100ms窗估计，早期0.05–0.25s的gamma约2.719/s，后期0.5–1.5s约2.308/s（tau约0.433s）。
  测量对窗长、频率漂移和噪声敏感，是单音证据，不是全音域阻尼结论。
- 在无ADSR、无body且持续held gate的自然衰减比较中，吉他模型1秒RMS相对起音约-29.34dB，录音约-15.71dB。
  录音尾部含残余噪声和非模态成分；不能把总RMS差额全部当作缺失的谐波持续。

### 为什么不能只加release

模态半径r=exp(-gamma/Fs)决定自然振动。release只在松键后额外乘输出包络并延后清历史。
若模态本身已经衰减至很低，延长release不能恢复能量。
此前吉他候选A≈0.5ms/D80ms/S15%/从S R120ms是控制变量听测，不是用户确认的最终吉他包络；
模态已自然衰减时，再套快速下降到15%的D会产生第二次幅度衰减，可能进一步削弱尾音。
因此应先检查自然阻尼，再选更温和的输出包络；从S的release与从满幅release时间不可混写。

### 为什么可能相似

两者都被简化为若干衰减正弦模态，系数不同并不保证保留全部听觉差异。
当前模型没有从原录音保留每模态初始相位、拨弦摩擦/击弦瞬态及各频段的多阶段包络。
eng0的gq/gv可分别作用于位移/速度；eng1单一G输入匹配模态峰值，不保证一般情况下复制其传递函数分子/初始相位。
这些都是建模缺口线索，不据此直接断言必须增加某个噪声或修改递推结构。

### 下一步优先级

1. 先用同音原录音对照确认目标吉他类型及录音质量；原录音自身若不合适再换源。
2. 按实际选定拨弦波形重建/验证G，重测逐模态gamma、频率、相对幅度，特别检查旧gamma_scale是否仍适用于新整数链。
3. 对比自然衰减的频带包络及起音，再设计吉他独立的ADSR/松键阻尼；不能照搬钢琴512ms并假设能补自然尾音。
4. 选定之后再迁入生产RTL；当前不把尚未匹配的A类试听系数直接替换正式资源。

### 阻尼/幅度怎样重算

1. 使用每个实际来源录音和已保留的模态频率，以4096样本（约85ms）Hann窗对该模态做复数投影，每35ms测一次幅度。
2. 在起音后15–725ms内，排除低于峰值-28dB、或距录音末段估计底噪不足12dB的点。至少5点才拟合。
3. 对log幅度做Theil–Sen稳健直线拟合；斜率须为负、gamma须在0.05..200/s且R²≥0.65。否则退回该来源原始、未乘校准的gamma。
4. 所测7个目标音符共156个模态位置中，77个通过这套准入，其余回退。没有将不可靠尾部强行拟合成长尾。
5. 新极点用r=exp(-gamma/Fs)、a1=-2r cos(theta)、a2=r²，重新量化到当前Q2.24/UQ0.24；保持原目标频率。
6. C/D/E用实际2采样激励的整数系数对应单位响应重新标G，保持各模态初始峰值，不以G变大伪装尾音改善。
7. F从录音投影幅度重新估计相对模态幅度，并按现有吉他body在模态频率处的幅度作补偿，逆补偿最多18dB。
   若整音G超出signed26头部空间，对该音全部G作同一比例缩放，而非逐模态截顶；MIDI74的公共比例约0.543，其它本段用音为1。
   这会影响跨音符响度标定，F目前用于听相对频谱，不是已经定稿的力度/跨音高增益曲线。

所有变化都保留线性递推结构。原录音的初始相位、拨弦摩擦和多阶段包络没有在本轮完整重建，不能由尾音更长推导音色已逼真。

## 压力调制与50音分

以下为2026-10-31的eng0压力调制测量，不是eng1 Bend/CC1算法。

### 已实现的修改

```
TH = PAD_NOTE_ON_TH
MAX = MAX_LAMBDA_Q30 = 37580959    // 保留原上限，约 0.035
FULL = 230
STEP = round(MAX / (FULL - TH))
lambda_q30 = MAX                       fmap >= 230
             0                         fmap <= TH
             STEP * (fmap - TH)         其余
```

这是力度对频率比例增量 lambda 的线性映射。固定整数步长四舍五入，230 起使用精确 MAX，之后一直饱和；不能把它等同于音分严格线性。阈值 102 的 STEP=293601，64 的 STEP=226391。TH>=230 的兼容入口没有线性区间，230起阶跃到上限（避免 MIDI 等旧默认入口因零分母而失效）；正常压力入口应使用 TH<230。note_on 判定为 `fmap > TH`，因此正常压力入口首个有效力度 TH+1 有一个步长的音偏。2026-10-31 按用户要求将满幅压力从255改为230，保留前四模态与原lambda上限。

lambda 在接受 start 的时钟锁存；一次任务的全部字段/模态共用该快照。此前 fmap 在任务中改变会让不同字段采用不同 lambda，本次已修正。仍从独立基值计算，维持幂等。

### clamp 能解决什么

1. **限制 lambda：有效，但只能在已经验证稳定的范围内。** 当前前四模态可以将上限缩到约 50 音分。若要全 20 模态共用同一个保守上限，目录扫描得到的一个可用候选是 Q30=7557269，名义约 12.142 音分。它来自稳定边界搜索后再留 2% 余量，已检查三个阈值的全部实际压力码；这是候选值，既不是精确最大值，也不证明任意连续变化都稳定。
2. **把 a11/a12/a21/a22 各自 clamp 到 [-1,1]：不能保证稳定。** 稳定性取决于整组矩阵的 trace/determinant，所有元素都小于 1 仍可能有极点大于 1。a11>1 也不是普遍适用的不稳定判据。
3. **把 q/v 或输出硬限幅：只限制爆音幅度，不能消除自激。** 可能形成持续饱和/极限环，不能作为调制稳定方案。
4. **对整组系数做稳定域投影：可以作为方案，但需要计算/验证。** 对具有共轭复极点的候选矩阵 A，`rho=sqrt(det(A))`。若超出目标半径 r，可令 `A_new=(r/rho)*A`，同时缩放四个递推系数，保持极点角度，压回极点半径。重新量化后必须再检查 Jury，并留足余量；实极点情况另行处理。wo 不决定递推极点。在线求根/除法成本较高，适合先离线生成按音符/模态/力度的稳定表或分段参数，不能只 clamp 一个字段。

一阶展开为什么会向外漂移：以简化的阻尼旋转矩阵为例，令 theta 为原每采样相位，delta=lambda*theta：

```
A_linear = r * [[cos(theta)-delta*sin(theta), sin(theta)+delta*cos(theta)],
                [-sin(theta)-delta*cos(theta), cos(theta)-delta*sin(theta)]]
rho(A_linear) = r * sqrt(1+delta^2)
```

一阶切线引入二阶半径增长；theta 较大的高模态先越过单位圆。只限制元素数值没有消除这个机制。

### 若要求全音色稳定达到 50 音分

建议改为生成固定目标半径、目标相位的系数，再经量化稳定性检查，不再直接扩大一阶线性矩阵的适用范围。可选离线稳定投影表，或重新组织为归一化阻尼旋转状态：`z[n+1]=r*R(theta_new)*z[n]+b*x[n]`。后者在同一固定状态基底且精确运算下，每一步的范数收缩为 r，任意变化的相位也不会引入切线增益；但需要重做状态/输入/输出系数，不能直接塞入当前参数表。RTL 定点舍入与有限幅度也仍须验证。

动态调制不能只检查冻结系数的极点。当前各模态逐条写回，没有整个声部的帧边界原子提交；本次锁存 lambda 消除了任务内压力撕裂，但未增加双缓冲。正式扩大音偏/模态数前，应做全模态同帧提交、压力变化速率限制（保持稳态映射线性），再验证最坏跳变、往返扫频和持续音的状态能量。速率限制本身也不构成稳定性证明。本次未宣称任意压力序列稳定，未做布局布线时序签核。
