## 烧录（命令留档）

工具：`openFPGALoader`（此前使用的 board 名为 `tangmega138k`），或 Gowin Programmer。

### 1. 先做 SRAM 下载（推荐，易失，不动 Flash）

```bash
openFPGALoader -b tangmega138k --freq 2500000 \
  build/pnr_20261102_0613/instrument_board/impl/pnr/instrument_board.fs
```

或 Gowin Programmer → `GW5AST-138B` → SRAM Program → 选择该 `.fs`。

这条路径不改外部 Flash，最适合先确认新固件能启动、音频/LED/界面正常。

### 2. 持久化到外部 Flash（确认 SRAM 版本正常后再做）

```bash
openFPGALoader -b tangmega138k --freq 2500000 --write-flash --verify --offset 0 \
  build/pnr_20261102_0613/instrument_board/impl/pnr/instrument_board.fs
```

或 Programmer → External Flash Mode → 地址 `0x000000` → Program/Verify。

实际写入的是解析后的二进制位流（约 5–6MB），不会覆盖 `0x800000` 起的资源区；这与 11-01 已验证过的烧录路径一致。
