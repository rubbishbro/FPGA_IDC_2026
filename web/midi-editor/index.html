连接 FPGA

在 Chrome / Edge 打开本地页面。使用与 RTL 一致的波特率；板端先选择有线 MIDI、对应音色 / 通道及音组，再核对已加载音高清单。播放器只发送音符和踏板 / 清音控制，其他 MIDI 控制事件保留在工程及导出文件中。

板端目前是单音色、固定 16 个槽。UART 播放前检查通道、缺失音高和同音重叠。TX 计数表示主机写入量，不能代替硬件生效或 I2S 出声确认。

本版本支持 4/4 拍，MIDI format 0 / 1 与变速图。导出 MIDI 包含全部轨道，静音 / 独奏只影响播放。草稿仅存在此浏览器，建议另存工程。
