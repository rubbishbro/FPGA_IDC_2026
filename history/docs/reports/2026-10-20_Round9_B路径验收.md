# Round 9 验收：B 类多声部激励池（x 生成）

- 日期：2026-10-20
- 范围：Round 9「B 每采样路径」的第一块——Control 解析 + 多声部 `x` 生成
- 结论：**B/C 顶层路径、BUF 读、C timer、a1 刷新（θ ROM + a1 shadow）已接；ENG2 实际数据仍未接**

## 1. 本轮做了什么

新增 `rtl/core/b_x_pool.sv`：

- 每声部一个 `b_voice_ctrl`（分数 NCO + AR 包络 + velocity）；
- 从 256-bit Control 记录里解析 B 的 `base_inc` / `attack` / `release`；
- 只有 `class==1` 的声部输出 `x`，A/C 声部输出 0（A 的 x 由外部 mux）；
- `ratio` 全局输入（UQ1.15），本轮固定 1.0 验证；
- 参数化 `NUM_VOICES`，测试用 2 声部，综合可扩到 32。

### 顶层接线（本轮增量）

- `modal_engine` 新增 `ctrl_flat[NUM_VOICES*256-1:0]`，把 per-voice Control 暴露给 top。
- `eng1_voice_top` 例化 `b_x_pool`，按 `b_class_vec` 做 `x_vec` mux：
  - `class=0(A)`：外部 `x_vec`；
  - `class=1(B)`：`b_x_pool` 的 x；
  - `class=2(C)`：0。
- `synth_top` 透传 `b_class_vec`、`b_vel_vec`、`b_start_mask`、`b_gate_mask`、`b_ratio`。
- B 的 Control 测试字带 `base_inc=0x40000000`、`attack/release=0x800000`，验证 NCO 脉冲。
- **BUF 读**：`class_loader` / `class_loader64` 增加 `USE_BUF` 与 `buf_rd_en/addr/data`，经 mux/engine/eng1 接到 `synth_buf.rd1`；`test_synth_top_buf` 先把 A 系数写进 BUF 再装载，mix 非零。
- **C timer**：`eng1_voice_top` 每声部例化 `c_voice_timer`，`c_length_vec/c_choke_mask` 从 `synth_top` 透传；C 装载后 active→done，`test_synth_top_c` 已断言。

### Control 字段约定（本轮冻结）

| 位 | 字段 | Q |
|---|---|---|
| `[15:0]` | `period_T` | 整数采样 |
| `[39:16]` | `attack_step` | UQ0.24 |
| `[63:40]` | `release_step` | UQ0.24 |
| `[95:64]` | `base_inc` | UQ0.32（新增，避免除法器） |
| `[119:96]` | 保留 | — |
| `[135:120]` | `noise_gain` | 本轮不消费 |

- `base_inc` 放 Control 保留区，生成器同时写 `period_T` 和 `base_inc`；L0 只用 `period_T`。
- `class_vec` 每声部 2-bit：`0=A`、`1=B`、`2=C`。
- `x` 的 Q 与 `b_voice_ctrl` 一致：`x = impulse ? env*vel >> 17 : 0`（Q2.30 附近）。
- `ratio`：UQ1.15，`1.0 = 0x8000`。

1. **ENG2 实际数据**仍 tie-off；`modal_voice_top` 只是壳，未接 BUF/结果。

4. e02/e07 未重跑；A/B/C 混音测试未做。
