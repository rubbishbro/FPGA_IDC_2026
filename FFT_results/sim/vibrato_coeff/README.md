# 颤音 a1 系数调制实验

生成脚本：`python/modal_sim/vibrato_coeff.py`  （深度 ±20 cents，LFO 5.2 Hz，控制率 96 采样 = 500 Hz）

## 1. 结论摘要

- **系数怎么变**：颤音只改 a1，a2 不变。`a1(rho) = -2 r cos(rho*theta)`，`rho = 2^(cents/1200)`；在 ±20 c 内它几乎是 `a1` 的一条直线。
- **线性近似够不够**：在浮点里，一阶 Taylor 的最大音高误差约 **0.14 c**（全乐器/全音域），二阶约 **0.002 c**。所以“线性调制”在数学上是够的。
- **真正的瓶颈是定点位宽**：当前 RTL 的 a1 影子是 Q2.20，在 cello C2（65 Hz）1 个 a1 LSB 就是 **11.3 c**；从 0 到 +20 c 的真实变化只有 1.8 LSB（±20 c 全范围 3.6 LSB），而 `term1 = (s*dtheta)>>6` 又把它截成整数个 a1 LSB，最终只有 **4 个电平**。Q3.14 的 δθ 只是第二层限制。
- **时域**：96 采样（约 2 ms）更新足够；系数切换引入的状态跳变在 -122 dB 以下，没有失稳。B 类的音高由驱动 NCO 决定，a1 量化主要影响共振/音色；A 类自由衰减的音高直接由 a1 决定，量化台阶会直接变成音高台阶。
- **建议**：router 只发“深度（cents）+ 速率”，不要发 a1 增量；每个控制 tick 用 per-mode 的 `theta/r` 算 `a1`。如果要把 20 c 颤音做到低音也平滑，把 a1 影子从 Q2.20 加到 **Q2.24**、δθ 从 Q3.14 加到 **Q3.20**（a2 仍固定）。

## 2. 系数公式与数值

```text
y[n] = g*x[n] - a1*y[n-1] - a2*y[n-2]
a1 = -2 r cos(theta),  a2 = r^2,  r = exp(-gamma/fs)
rho = 2^(c/1200)  (c = cents)
a1(rho) = -2 r cos(rho*theta),  a2 unchanged
da1/dc = -2 r sin(theta) * theta * ln2/1200  (at c=0)
```

cello C2 基频 θ=0.008560 rad，r=0.99988016；0→+20 c 对应 a1 变化 1.80 个 Q2.20 LSB。

| cents | exact a1 (float) | Q2.20 current | Q2.24 proposed |
|---:|---:|---:|---:|
| -20 | -1.999688736 | -1.999689102 | -1.999688864 |
| -10 | -1.999687904 | -1.999688148 | -1.999688029 |
| +0 | -1.999687062 | -1.999687195 | -1.999687195 |
| +10 | -1.999686211 | -1.999687195 | -1.999686360 |
| +20 | -1.999685350 | -1.999685287 | -1.999685466 |

## 3. 线性近似误差（浮点）

| 方法 | 全乐器最差音高误差 (c) | 说明 |
|---|---:|---|
| 一阶 Taylor（线性） | 0.137 | cello F#4 |
| 二阶 Taylor | 0.002 | cello F#4 |
| 端点 secant（线性插值到 ±20 c） | 0.473 | cello C2 |

一阶误差随深度按二次方增长；±20 c 时 < 0.2 c，远低于 ~5 c 的可闻阈。二阶项在 ±20 c 内 < 0.01 c，基本是“免费”的精度，但只有在定点位宽足够时才有意义。

### 线性斜率随模态变化（cello C2）

`da1/dc = 2r sin(theta)*theta*ln2/1200`，低音模态下约与 k² 成正比：

| 模态 k | f (Hz) | da1/dc (Q2.20 LSB / cent) | 相对 k=1 |
|---:|---:|---:|---:|
| 1 | 65.4 | 0.0888 | 1.0x |
| 2 | 130.8 | 0.3550 | 4.0x |
| 4 | 261.6 | 1.4198 | 16.0x |
| 8 | 523.2 | 5.6757 | 63.9x |
| 16 | 1046.3 | 22.6496 | 255.2x |
| 32 | 2092.6 | 89.7478 | 1011.2x |

所以**不能**把同一个 `Δa1` 加到所有模态：必须让 router 发 `cents/ratio`，engine 用每个模态自己的 `theta` 展开；否则高次模态会欠调制约 k² 倍。

## 4. 定点才是瓶颈

下面的“当前 RTL”指 `history/rtl/core/legacy_frontend/b_a1_refresh.sv` 的整数算法（a1 Q2.20、theta UQ2.14、ratio UQ1.15、δθ Q3.14、a1 shadow Q2.20）。实验按它的移位/饱和顺序逐位建模，而不是只把浮点结果四舍五入。

| 配置 | cello C2 | cello C3 | cello C4 | 全乐器最差 |
|---|---:|---:|---:|---:|
| a1 Q2.20, 理想 δ | 7.34 | 2.54 | 0.62 | 7.34 |
| 当前 RTL: Q2.20 + δθ Q3.14（整数） | 13.87 | 5.01 | 3.29 | 13.87 |
| a1 Q2.24, 理想 δ | 1.95 | 1.19 | 0.29 | 1.95 |
| Q2.24 + δθ Q3.20, 一阶（浮点多项式） | 2.07 | 1.22 | 0.43 | 2.07 |
| Q2.24 + δθ Q3.20（整数） | 1.82 | 1.36 | 0.34 | 1.82 |

注意：这里的误差是相对“目标音高”的绝对值，包含静态 a1 Q2.20 的调音误差（cello C2 为 -1.57 c）。只看颤音本身的相对误差，当前 RTL 在 C2 仍有 12.3 c；Q2.24 + Q3.20 可降到 0.65 c。

还要注意：Q2.24 只加宽了**调制后的 a1**，标称 a1 仍来自 Q2.20 ROM，所以 C2 的静态调音误差 -1.57 c 仍在。要绝对音准，需要在 note-on 用更高精度重算 a1_nom（或把 ROM 的 a1 也加宽）。另外，当前 RTL 的 `dtheta` 和 `term1` 都用算术右移（向下取整），负半周会被多压一点；C4 从 0 到 +20 c 只有 ~6 个 δθ 台阶，造成最大约 3.3 c 的向下误差。加宽到 Q2.24/Q3.20 后这个偏置可以忽略。

### 为什么低音最差

| 音 | 1 个 a1 Q2.20 LSB = | ±20 c 全范围 a1 变化 | 当前 RTL 电平数 |
|---|---:|---:|---:|
| C2 | 11.27 c | 3.6 LSB | 4 |
| C3 | 2.82 c | 14.2 LSB | 8 |
| C4 | 0.70 c | 57.1 LSB | 14 |
| C5 | 0.18 c | 225.8 LSB | 27 |
| C6 | 0.04 c | 901.1 LSB | 53 |

C2 上从 0 到 +20 c 只有 1.8 个 LSB 的真实变化（全范围 3.6 LSB），截成整数 LSB 后只剩几个 10 c 级台阶；C4 以上每 LSB < 1 c，听起来才连续。

## 5. 时域结果

| 乐器/音 | 配置 | 与浮点参考的 null | 最大系数跳变 |
|---|---|---:|---:|
| cello C2 | q20_int | -16.8 dB | -116 dB |
| cello C2 | q24_int | -27.5 dB | -122 dB |
| cello C4 | q20_int | -14.0 dB | -100 dB |
| cello C4 | q24_int | -30.0 dB | -100 dB |
| flute A4 | q20_int | -19.4 dB | -94 dB |
| flute A4 | q24_int | -36.6 dB | -95 dB |
| trumpet C4 | q20_int | -17.5 dB | -93 dB |
| trumpet C4 | q24_int | -27.5 dB | -94 dB |

- 系数每 96 采样切换一次，切换处的状态跳变约为 `Δa1*y1`；在 20 c 深度下最大也只有 -100 dB 量级，不需要额外的状态补偿。
- B 类（持续音）的基频由驱动 NCO 决定，所以 a1 量化不会把颤音音高变成台阶；它改变的是各模态的共振幅度/相位。cello C2 的 null 为 -16.8 dB（Q2.20）与 -27.5 dB（Q2.24）；C4 更明显（-14.0 dB vs -30.0 dB），因为 Q3.14 δθ 在 C4 已有最大约 3.3 c 的误差。
- A 类（自由衰减）没有持续驱动，音高直接由 a1 决定；当前 RTL 在 C2 的 20 c 颤音会变成几个 10 c 台阶，见 `fig_staircase.png` / `fig_free_decay.png`。

## 6. 实时调制建议

1. **router 只发参数，不发系数**：旋钮 0..1 线性映射到深度 `D`（0..20 cents），再发速率 `f_vib`；LFO 相位和 `ratio` 放在 router 后面的 expression 小模块（或 refresh 引擎的控制口），router 本身不做 per-mode 乘法。每个控制 tick 每声部算 `c = D*sin(2*pi*f_vib*t)`。
2. **每声部一个 ratio**：`rho = 2^(c/1200)`（UQ1.15 足够，20 c 约 380 LSB）。不要所有声部共用一个相位，否则所有音会同时颤；现有 `b_a1_engine` 只有一个 `ratio` 输入，要做独立相位就得每声部一个 ratio 寄存器，或在 refresh 引擎里按声部相位现算。
3. **per-mode 刷新**：`delta_theta = (rho-1)*theta`，`a1' = a1 + s*delta_theta - a1*delta_theta^2/2`（当前公式），`s = sqrt(4a2-a1^2)`；`a2` 不动。20 c 用途下二阶项只多修 ~0.7 c（C2），可以只做 `a1 += s*delta_theta`，省掉 d2/term2 的乘法；若要 ±50 c 或滑音，再保留二阶或直接 cos。
4. **更新率**：每 96 采样（500 Hz）足够；5.2 Hz 颤音每周期约 96 个更新点。不需要 per-sample cos。以上假设一个 tick 内该声部全部模态一起换 a1；如果 RTL 逐模态写 shadow，需要双缓冲/影子区，避免同一采样内新旧系数混用。
5. **位宽**：如果目标包含 cello C2 的 20 c 颤音，把 a1 影子（包括 term1）做成 Q2.24，δθ 用 Q3.20；否则 term1 仍然被截成整数个 a1 LSB，C2 只有几个台阶。
6. **深度变化要 slew**：0->20 c 的阶跃相当于 a1 跳满整个 span；实测单次跳变的峰值约 -96 dB（C2）、-82 dB（C4）、-69 dB（C6），虽不刺耳，但快速拧旋钮时建议给深度加 10–20 ms 一阶平滑。
