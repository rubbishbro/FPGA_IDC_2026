# 真实音频频谱显示 实施计划（v3：板上自研 FFT）

> 方案升级：不再"离线预计算频谱"，而是**存储真实音频 → 板上自研 FFT → 频谱**。
> 整条链路真实，且可同时验证波形合成算法与李萨如。
> FFT 用现有 pix_clk(33.33MHz)，不新开时钟域，架构简化。
> 顺序：先音频下载+频谱，后波形/李萨如。

---

## 一、架构总览（全工程单时钟域 pix_clk）

```
[audio_rom]  8秒真实乐曲 16bit@48k（BSRAM ~768KB）
     │ 循环播放（48k 节奏，pix_clk 分频 ~694拍/采样）
     ▼
[时域乒乓 A/B]  1024×16bit（攒点）
     │                              ┌→ [波形显示]（后做，直接从时域乒乓读）
     ▼                              │
[fft_engine 自研] 1024点基2，pix_clk   │
     │  旋转因子 ROM + 数据 RAM       │
     ▼                              │
[频域乒乓 bar_h/ov ×2]  ←──┐          │
     │                     │          │
     ▼                     │          ▼
[spectrum_map 对数轴+dB]    │      (phase2)
     ▼                     │
[频域乒乓]──────── 显示读 ──┘
     ▼
[lcd_fft 光点/灯阵] → 屏幕
```

**关键**：`fft_engine` 是占位（模拟用），最终由同学的 FFT IP 替换。
**乒乓之后的所有算法**（频域乒乓→对数映射→柱高→光点→显示）与 FFT 无关，直接复用。

## 二、时序预算（pix_clk 33.33MHz，周期30ns）

| 环节 | 计算 | 耗时 |
|---|---|---|
| 48k 采样节奏 | 33.33M/48k ≈ 694.4 拍/采样 | 每采样 20.8μs |
| 攒满 1024 点 | 1024 × 694 拍 | **21.3 ms** |
| FFT 计算 | 5120 蝶形 × ~10拍/蝶形 ≈ 5万拍 | **~1.5 ms** |
| 频域映射 | 512 bin × 1拍 | ~512 拍 |

**FFT ~1.5ms << 攒点 21.3ms，富余 14 倍** —— FFT 每次攒满后集中算完，不追尾。

```
时间轴:
  攒A(21.3ms) ──→ FFT算A(1.5ms) ──→ 写频域乒乓A
        攒B(21.3ms) 并行 ──→ FFT算B ──→ 写频域乒乓B
  循环，频域乒乓翻转给显示读
```

## 三、模块分工

### 1. audio_rom（真实音频存储 + 播放节奏）
- BSRAM 存 8 秒音频：`NFRAME_SAMPLES = 8 × 48000 = 384000 采样 × 16bit = 768KB`
- pix_clk 分频计数（~694）产生 48k 节奏 `samp_en`
- `samp_en` 时从 ROM 读一采样 → 写入时域乒乓；地址循环

### 2. time_pingpong（时域乒乓）
- A/B 各 1024×16bit
- 音频写一块（samp_en 驱动），攒满 1024 → 触发 FFT
- FFT 读另一块

### 3. fft_engine（自研 1024 点基2 FFT，pix_clk）
- **数据 RAM**：1024 × 复数(16bit re + 16bit im)，BSRAM
- **旋转因子 ROM**：512 × 复数(16bit)，预生成
- **蝶形单元**：DIT 基2，每级 512 蝶形 × 10 级
- 幅值输出：`|re|+|im|` 近似（免 sqrt）
- 输出 512 有效 bin

### 4. spectrum_map（bin→柱高）
- 对数频率轴（20Hz..20kHz，bin2bar ROM）
- 幅值 → 20·log10 查表 → 0..479
- 超调 = 柱高×1.2 clamp 479

### 5. freq_pingpong（频域乒乓）
- 两块 bar_h/ov（各 128×10bit）
- FFT 写一块，显示读另一块，翻转

### 6. 显示复用
- lcd_fft（光点/灯阵）——**不改**
- lcd_draw —— **不改**

## 五、资源占用估算

| 模块 | BSRAM | LUT/REG | DSP |
|---|---|---|---|
| audio_rom | 768KB(~6Mbit) | 小 | - |
| 时域乒乓 | 2×1024×16 = 32Kbit | 小 | - |
| FFT 数据 RAM | 1024×32 = 32Kbit | - | - |
| FFT 旋转因子 | 512×32 = 16Kbit | - | - |
| 频域乒乓 | 2×128×20 = 5Kbit | - | - |
| **合计** | ~6.1Mbit | 中 | ~10-20 |

BSRAM 总量 6120Kbit，audio_rom 用 ~6Mbit → **基本占满**。若不够，把音频降到 12bit 或减到 6 秒。
> ⚠ 注意：audio_rom 6Mbit + FFT 等 ≈ 6.1Mbit 已接近上限，**S1 建议先试 6 秒（~4.6Mbit）留余量**。
