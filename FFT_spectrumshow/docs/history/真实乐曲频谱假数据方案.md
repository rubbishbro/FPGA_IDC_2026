# 真实乐曲频谱假数据 实施方案（方案2）

> 目标：下载公有领域乐曲 → 离线 FFT → 导出 128柱频谱序列 → FPGA 存 ROM 播放。
> 不仅当频谱假数据，还能用于验证：波形合成算法、李萨如图形、双通道延迟相图。
> 板子：Sipeed Tang 138K Pro（GW5AST-138B），BSRAM 6120 Kbit，容量充足。

---

## 一、总体思路

```
[Musopen CC0 乐曲] → 本机 Python 离线处理 → Verilog 初始化文件(.mem/.hex)
                                                        │
                                                      存 ROM
                                                        │
                                                  FPGA 每帧查表播放
```

**核心洞察**：FFT 由同学负责，但我们离线算好的频谱序列**本身就是真 FFT 的输出形态**——
它每帧更新 128 柱，正好是 `bar_h_ram` 需要的数据。方案2 = "用真乐曲的离线 FFT 结果当假数据"，
一举三得：频谱假数据 + 波形算法验证 + 李萨如信号源。

## 三、离线处理流程（本机 Python）

### 3.1 素材下载
- **Musopen**（CC0 古典乐，可下载 WAV/OGG）：https://musopen.org/
- **Internet Archive**（CC0 合集，如 Musopen-Libre，OGG/MP3）：archive.org
- 选一首 30~60 秒、有动态的（钢琴/管弦乐片段，别选单音长音）

### 3.2 Python 离线 FFT 脚本（伪代码）

```python
import wave, numpy as np

sr = 48000;  N = 1024;  NBAR = 128
# 1. 读 WAV
y = read_wav("song.wav", sr)          # 单声道 float
# 2. 分帧 + 加窗
frames = [y[i*N:(i+1)*N] * np.hanning(N) for i in range(len(y)//N)]
# 3. 每帧 FFT → 幅值
specs = [np.abs(np.fft.rfft(f))[:512] for f in frames]   # 512 bin
# 4. 对数频率轴映射：128 柱，20Hz..20kHz
bins = log_axis_bin_map(f_low=20, f_high=20000, N=1024, sr=48000)
# 5. 柱高 = bin 组内 max → 20*log10 → 归一化 0..479
bars = [[db_to_scale(max(spec[b] for b in group)) for group in bins]
        for spec in specs]
# 6. 量化 10bit + 导出
write_verilog_init("spectrum.mem", bars)    # 每行 128 个 10bit 十六进制
```

### 3.3 输出格式
```
spectrum.mem: 每帧一行，128 个 10bit 值（0x000..0x3FF）
第 0 行 = 第 0 帧 128 柱柱高
```
Gowin 用 `$readmemh` 或 ROM 初始化读入。

## 四、FPGA 端：频谱播放模块（新）

### 4.1 存储布局
```
BSRAM 单块 ROM：NFRAME × 128 × 10bit
  例：30s → 1400帧 × 128 × 10bit = 1.79Mbit（用 2~4 块 BSRAM）
```

### 4.2 播放控制（替换现有 data_source 的 FFT 页）
```
每 frame_pulse：
  addr++（循环播放，mod NFRAME）
  从 ROM 读一行 128 柱 → 写 bar_h_ram[0..127]（频域乒乓）
  → 光点/绘制照常
```

### 4.3 波形页（验证合成算法）
离线时也导出**原始时域波形**（如 48k 采样），FPGA 存 ROM 播放：
```
每列扫 1 次 → 读对应时域点 → lcd_wave 画点
```
可对比"当前合成波形"与"真实乐曲波形"看算法差距。

### 4.4 李萨如信号源
离线导出**两路相关信号**（如左声道 + 右声道，或原信号 + 延时），FPGA 播放时：
```
X = 信号L → 映射横轴
Y = 信号R → 映射纵轴
→ 帧缓冲画点 → 验证李萨如
```
