# 频谱、显示与中文侧栏系统设计

更新：2026-10-29。本文描述可视化子系统，独立demo入口为 `board/ui_demo_top.v`，默认 SIDEBAR_UI=1；旧假数据源/光点教程保存在 [历史原理稿](history/系统设计原理_旧版.md)，v2 MCLK 图是目标方案，不是当前布线。

统一板级另为[instrument_board_top](../../rtl/platform/tang_mega_138k_pro/README.md)：复用LCD扫描/侧栏并接真实后端，控制100MHz、像素约33.333MHz；第一阶段没有FFT实例，读口接零。以下测试源/FFT数据流只适用于独立demo。LCD扫描共用修复后的800×480有效区及1192×533总周期。

## 1. 时钟、复位和数据源

板载 50MHz 进入 PLL 生成约 33.333MHz 像素时钟。FFT/采样缓冲/绘制在 demo 中都使用像素时钟；侧栏配置控制使用 50MHz。复位分别在各域同步释放，跨域 mailbox 要求共同复位断言，不能独立清一端。

默认输入为内部三音测试源，可参数选择 1–10kHz 扫频。它们用于独立频谱验证，尚未接主合成器 PCM。real_audio_chain 虽保留 core/pix 两组时钟端口，当前使用方式是同域，不证明可以直接接任意异步时钟。

```text
测试 PCM → time_pingpong → fft_ctrl/fft1024_iter → spectrum_map
        ├→ wave_capture / wave_frame_buffer
        └→ 频谱历史/曲线计算 → trail/curve/frame buffers
显示扫描 → 读取稳定 bank → lcd_draw → 底图
                                  → 中文侧栏覆盖 → RGB/DE 同步延迟 → 引脚
```

主音源接入需要定义 signed64→24 bit PCM 的缩放/饱和，再经过音频异步 FIFO，在像素域发布一拍 pcm_valid。该数据 CDC 与侧栏配置 CDC 是不同通路。

## 2. 显示结构

样式编号 0=BARS、1=WAVE、2=FALL，16 bit style_id 先显式注册/校验，再映射到现有绘制分发。未知编号返回 UNSUPPORTED，不能截低两位。

频谱映射、历史/曲线计算及缓冲在帧/计算路径完成，像素路径主要查 RAM、比较坐标和颜色选择。同步读有延迟时，坐标/有效/数据需同级对齐。越界柱/采样地址按明确窗口裁剪，不能将消隐坐标夹到末柱造成残影。

旧光点的超调/下落、灯阵颗粒等原理仍可参考历史教程；当前样式/主题/峰值/平滑/网格由实际 active 配置控制。默认侧栏覆盖左 288px，主图不缩放、不暂停。

## 3. 配置与交互

```text
raw X/Y → joystick_adapter ─┐
双按键 → key_ui_event ──────┤→ sidebar_ctrl
                           → control_loop → config_dispatch
外部已转换统一请求 ────────┘                   ├→ 显示快照
                                              ├→ 校准
                                              └→ backend
显示快照 → sidebar_mailbox → 像素帧头应用 → 结果返回原来源
```

请求 64 bit、结果 72 bit；来源/载荷反压保持，失败保持实际值。control_loop 只轮询和转交；菜单/草稿是控制域状态，开合动画在像素帧头推进，默认 12 帧。应用显示项需等目的端帧头真实应用，不以进入轮询暂存为成功。

独立 demo HAS_JOYSTICK=0，双按键可开栏、上下/确认/返回；真实摇杆采集出口可接 sidebar_system。音量/乐器/混响/来源等参数必须有真实消费者才开放，demo 后端能力为 0。

lcd_sidebar 从180字形的16×16 ROM读取中文/ASCII；布局/字模三级流水及最终输出寄存使RGB、DE统一延迟四拍，底图同步对齐，数字和滑条在消隐期准备。字库与字体授权见 `board/sidebar_font.LICENSE`。

## 4. 验证及边界

`python3 sim/run_ui.py --legacy` 本轮通过 17 组，包含系统 CDC/帧头/结果、字模/动画/裁剪及原 14 项 FFT/WAVE/FALL/按键回归。测试不证明真实 LCD 电气/主音频输入/ADC。

既有 LCD demo PnR 报告在 50MHz/33.333MHz 下 setup/hold 0/0、最差 +1.448/+0.216ns；本轮仅解析复核报告，没有重新 PnR 或上板。该数字不适用于100MHz音频整机；统一板级已有实际PnR报告但时序失败，当前状态见[工程验证](../../docs/工程评审与验证.md#board-integration-2026-10-29)。

外部端口、参数字典、CDC/复位约束和构建方式分别见 [实施接线](../../docs/控制与侧栏设计.md#integration)、[demo README](../README.md) 与 `sim/synth/sidebar_build.tcl`。
