# 8×8 打击垫 LED 灯效

`instrument_system` 将标定后的 `force_map` 接到 `pad_led_effects`，仍由
`pad_driver.led8x8` 输出串行 GRB 数据。新灯效使用 50MHz 核心时钟处理，
400ns `clk_en` 负责调度 200Hz 画面和显存写入，没有新增时钟域。

## 画面与取色

- 背景为固定白色色相的明暗行波，周期约 5.2s，波长 4.2 格，从逻辑灯 `(0,0)` 向外传播。
- 每个垫仍对应 2×2 灯区，但击打波纹覆盖整个 8×8 灯阵。
- 压力 `>64` 起触发，`<48` 释放，中间保持；按住不重复触发，松开不截断尾波。
- 对垫 `(row,col)`，在触发沿立即保存**当前已显示帧的全局相位**。
  随后加上左上灯 `(2*col,2*row)` 的固定相位偏移，查表选出一个色号。
  色号在整个波纹生命周期内不变，主峰和所有旁瓣同色，只改变亮度。
- 256 个相位地址映射至 56 个色号：红、橙、黄、绿、青、蓝、紫，每族 8 个色调。
  同族渐变发生在不同触发相位的取色之间，不沿一条波纹跨族换色。
- 波源中心是 `(2*col+0.5,2*row+0.5)`；传播速度约 6 格/s，固定波宽 0.65 格。
- `abs(sinc(pi*u))` 保留主峰和衰减旁瓣，`u=(R-r)/0.65`；未到达的点不发光。
  `u=6.6..9` 平滑收尾，另查时间衰减和可选径向衰减（`RADIAL_DECAY`）。
- 16 条波纹按触发先后分配，满池替换最旧记录，同垫连击可保留旧尾波。
  重叠处保留亮度最大的波纹，不相加不同色族；相等时保留先扫描到的记录。

## 定点数据与资源

全局相位使用 Q0.32 循环累加器，每帧加 `4129776`；半径行程使用 Q8.16
循环累加器，每帧加 `1966`。事件保存起始行程，渲染时作差得到半径。
时间衰减每 50ms 一档，64 档覆盖约 3.2s；过期记录永久清除，避免计时器回绕后复活。

| ROM | 组织 | 原始字节 |
|---|---|---:|
| phase | 64×16 | 128 |
| breath | 256×8 | 256 |
| palette | 256×6 | 192 |
| distance | 64×12 | 96 |
| shape | 512×6 | 384 |
| age | 64×6 | 48 |
| radial | 64×6 | 48 |
| combine | 4096×6 | 3072 |
| colour | 3584×24 | 10752 |
| 合计 | 119808 bit | 14976（14.625 KiB） |

距离 ROM 使用横、纵绝对距离对称性，数据为 Q4.8；sinc 索引为落后波前距离的
1/64 格采样。`combine[a,b]=round(a*b/63)` 离线生成，运行时共享同一 ROM
依次施加两种衰减。运行时没有变量乘法、除法、开方或 HSV 转换。

RGB 表按 `pixel_t` 的 **GRB** 顺序存储。固定增益把背景峰值限制为 80、波纹峰值
限制为 160，每通道相加最多 240，既保留背景明暗也避免溢出/逐通道截断改变色相。
不使用逐帧峰值拉满。6 位亮度与 8 色调/族是对交互预览的离散近似。

ROM 为同步读，FSM 明确留出读延迟。每帧先锁存所有波纹状态，再串行扫描
64 像素×16 波纹，写满后才启动传输；不会在一帧中混入后到事件。
新 `busy/frame_done` 信号防止传输期间写显存，并在锁存间隔结束时更新已显示相位。
复位先写一整帧黑色，避免未初始化显存上屏。

实际 BRAM 块数需综合确认；相位表有事件取色/渲染两个同步读端口，可能映射为双端口
ROM 或复制。波纹池、待处理事件和帧快照使用少量寄存器，64×24 后台帧缓冲另计。
`FRAME_TICKS` 默认为 12500；它只是测试加速/调度参数，改真实刷新率时须同时调整
相位步长、半径步长和年龄分频，不能据此独立调动画速度。

## 生成与构建

```bash
python3 rtl/drivers/tools/gen_pad_led_tables.py
python3 rtl/drivers/tools/gen_pad_led_tables.py --check
```

表数据及 `manifest.json` 随源代码保存。默认 `TABLE_DIR` 为
`rtl/drivers/pad_led_tables`（相对运行目录）。整板 `build.tcl` 和
`sim/run_board.py` 会将表复制到各自构建目录内的相同路径；独立入口须从仓库根目录
运行或覆盖 `TABLE_DIR`。改变速度/周期/波宽时应同时修改生成器和对应 RTL 常量。

`tb_pad_led_effects` 已改为检查灰度背景、左上灯取色、锁色、同垫连击、16 垫同时触发、
退休、串行波形与复位；整板夹具改为核对完整 8×8 帧及蛇形接线。
本次仅做表生成一致性及静态编译检查，按用户要求未运行 HDL 仿真、综合或烧录。
