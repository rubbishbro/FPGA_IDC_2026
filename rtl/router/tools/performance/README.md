# 当前六音色资源（schema 5，未验收）

固定每乐器32音，16个按键加载低/高两组之一；上电和换音色默认低组。

| 音色 | ID | 全范围 | 低组（bank=0） | 高组（bank=1） |
| --- | --- | --- | --- | --- |
| 钢琴0 / 钢琴1 | 0 / 10 | 21–52 | 21–36 | 37–52 |
| 吉他0 / 吉他1 | 1 / 11 | 40–71 | 40–55 | 56–71 |
| 小号 | 3 | 51–82 | 51–66 | 67–82 |
| 小提琴 | 5 | 55–86 | 55–70 | 71–86 |

- `resources.bin` / `resources.mem`：同一资源字节，1576960字节（1540 KiB），从物理地址0x800000开始，不包含配置固件。
- 每乐器区域128 KiB，每音符4096字节；加载地址为 `FLASH_BASE + (instrument << 17) + ((bank*16 + key) << 12)`。每个乐器编号保留固定区域，未启用区为FF。
- 公共控制页移到0x980000，4096字节；位于12个乐器区域之后，页内布局不变。镜像结束地址为0x981000（不含）。
- `resources.json` 提供 `note_maps[name]` 和 `note_ranges[name]`；不再提供一组全局 `note_map` 或 `first_midi`。正式资源禁止用单一 FIRST_MIDI 解释全部乐器。
- word7 的 mode0/1/2 保存逐音valid/period、attack、release；其它字的矩阵/ABC/P1T1含义不变。

## 系数来源与补音

ENG0已有量化记录优先保留；其它有源音高从 sythsound 的完整矩阵浮点表量化。现存 ENG0 钢琴矩阵源最低为40，目标21–39离线从40的矩阵极点移调，保留衰减半径并调整输入映射的静态平衡；源号、补音标记记录在每条manifest条目中。FFT_results中钢琴21起的稀疏ABC源表与此ENG0矩阵源不同，不能混作原生矩阵记录。

钢琴1依照同一目标音高的ENG0矩阵提取极点，保留短击弦激励下的模态峰值，选择最多48个模态并生成ABC/P1T1。单个ABC输入项不等价于矩阵的完整传递函数分子，模态相位和听感仍待试听确认；不能宣称两格式逐样本等价。吉他1保留F版重拟合阻尼/幅度及温和包络；小号、小提琴缺音离线生成对应目标音高的系数，运行时不拿邻近音符替代。

## 前端接口

板上菜单“音域 → 键位音区 → 低音组/高音组”发送内部配置请求：`id=0x0300,value=0/1`，按既有cfg_valid/ready和真实完成响应提交。UI只在后端确认后显示已提交值。实际16键的音符通过guide_display.note_map发布。

网页 `src/resource-banks.mjs` 提供 `resourceBank(manifest,channel,bank)`，返回16音列表、起止音高和对应内部配置描述符。网页选择是资源核对接口，不会把内部0x0300当成线上COMMAND发送。通信协议未增加单独切组命令；当前COMMAND20每键独立乐器后端仍未实现。
