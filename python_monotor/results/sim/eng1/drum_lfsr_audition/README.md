# 鼓组 LFSR 试听与存储复用提案

> 以下存储映射是试听阶段提案。现行RTL已改为seed=0关闭、非0启用，
> 无新增控制端口，也不要求tag；以 `docs/ENG1_鼓噪声.md` 为准。

运行 `python3 python_monotor/modal_sim/drum_lfsr_audition.py`，仅依赖 Python 标准库。
这是拟议鼓通路的 Python 试听，未修改 RTL，尚未验证 FPGA 时序和资源。

## 试听

- `groove_compact.wav`：21秒，LFSR＋简化噪声整形，面向 RTL 的候选方案。
- `groove_fir.wav`：同段演奏，LFSR＋旧版257抽头 FIR 整形参考。
- `groove_dry.wav`：同段演奏，无噪声。
- `groove_AB_dry_compact.wav`：先无噪声，间隔1秒，再简化噪声版。
- `full_*.wav`：40秒，前段为六件鼓、力度、短按长按试听，19.2秒起为节奏。

三版共享完全相同的模态波形、演奏事件、鼓件增益和最终输出增益。
统一峰值上限0.85，不分别归一化、不软削波，无腔体或混响。

## 找到的旧方法

源代码：`python_monotor/fft_analysis/percussion.py` 的 `noise_filters/noise_signal`，
由 `python_monotor/modal_sim/drumkit.py` 调用；`drum_noise_compare.py` 是旧噪声开关对照。

旧方法为高斯白噪声，经257抽头、单位RMS的FIR频谱整形后，乘指数衰减包络。
支持LF/HF独立衰减以及独立频谱/包络的敲击瞬态。
当前 `drums.npz` 六件鼓的 gamma_lf/gamma_hf 都是0，实际走单尾音支路；
Ride/Crash 另有 attack 瞬态，因此当前最多两条噪声支路。
`noise_gain/env_gamma/att_amp/att_gamma` 和各自频谱均从原参数读取，不重新手调。

本次FIR参考把高斯噪声换成32位 Galois LFSR的双极性单比特输出。
频率采样法重建257抽头 Hamming FIR；使用因果卷积，较旧的居中裁切有
约128采样（2.62ms）的群延迟及不同起音边界，不能称为旧版逐样本复现。

简化版用两个一阶低通之差进行带通整形，离线搜索上下截止频率拟合原频谱。
噪声频谱形状是近似；滤波、包络为Q24整数更新，增益及最终混合为浮点。
使用单位平稳RMS标定，短瞬态的瞬时能量不保证与旧FIR完全一致。

## 与腔体模块的关系

此处滤波只处理噪声的频谱，不是乐器公共腔体滤波。
拟议链路：

    ENG1：模态递推 + (LFSR → 噪声频谱整形 → 噪声包络) → 声部相加
    引擎外：现有腔体 body_router → 现有混响/混音输出链路

保留现有腔体模块的位置和职责；本试听关闭腔体，不代表最终腔体预设。

## 模态存储槽复用

每个物理模态槽有7个32位co字段和2个32位状态字(q/v)。
普通模态地址0..47继续递推；物理深度64时，地址48之后可作特殊噪声记录。
每条简化噪声支路复用两个槽：

| 记录 | q状态 | v状态 | 参数建议 |
| --- | --- | --- | --- |
| 噪声主记录 | LFSR原始32位位图 | 包络UQ24 | 非零seed、包络初值、衰减系数、上下截止对应的一阶系数、增益、类型tag |
| 噪声扩展记录 | 下截止低通Q24状态 | 上截止低通Q24状态 | 扩展类型tag，其余字段保留 |

主记录7个co字段可依次映射 a11=seed、a12=env_init、a21=decay、
a22=alpha_lo、gq=alpha_hi、gv=gain、wo=type_tag。该映射仅为提案，尚未打包进Flash。
LFSR应按unsigned位图解释，不能走普通有符号状态饱和；0是清理后的停机状态，
起音须从非零seed初始化。初值与运行态分开存放。

当前参数：Kick/Snare/Tom/Hat各需2个额外槽（48/49），
Ride/Crash各需4个（尾音48/49、瞬态50/51）。
若日后启用独立LF/HF尾音，则最多3支路、6槽（48..53）。
若坚持只占1槽，只能放LFSR＋包络；独立整形滤波的状态必须另找存储，
无法仅靠2个32位状态字保存原257抽头FIR。

噪声运算作为ENG1内的另一类作业，复用现有每bank的读写口，分时调度；
读主/扩展两记录、锁存暂态、计算、各写回一次，结果只累加一次。
不能让扩展记录再作为ABC模态计算，也不能新增并发RAM读口破坏BSRAM推断。
现有48有效模态的调度须扩展为“48模态＋噪声特殊作业”，仅写入48之后不会自动执行。
job完成/y_valid须等待噪声也完成，时钟预算要单独仿真验证。

## 校验与边界

LFSR：右移Galois，mask=0x80200003，每采样输出一次双极性bit再推进一次。
通过GF(2)跳步验证周期2^32-1，校验其全部素因子3/5/17/257/65537。
各支路使用独立非零seed，约24.4小时周期（48828Hz）。
不把连续移位的多位字直接当均匀白噪声样本，以避免相邻样本位重叠造成的相关。

当前每次击打重置seed，重复击打的噪声序列相同。未来可保留连续状态或变化seed。
简化噪声滤波状态未越32位，模态状态无饱和，所有WAV无削波，数值见manifest.json。
继承的5ms重触发交叠保留旧尾音；RTL要有临时淡出状态，或改为先淡出再启动，
不能宣称已用单个固定声部完整实现该交叠。
输出48,828Hz（实际板时钟为48,828.125Hz）。本实验不包含ADC扫描、装载时序或板端电平。
