# E4 单长音：起音与稳态权重诊断

当前ENG1，85%保持新包络，腔体直通、无新增气息、无混响。未改生产RTL。
所有音频按起音后0.45..1.05秒稳定段RMS对齐，使用固定增益，无压缩。
原采样10% RMS阈值与模型note-on对齐，起音时间仅作近似比较。

## 主要证据

- 当前参数源为 flute_E4_15_forte_normal.mp3：第四谐波相对基频 +8.86dB。
- 当前模型：第四谐波 +10.01dB；H2..H8与强奏原采样的相对幅度误差中位数0.76dB；积分带宽12/25/40Hz的结果接近。
- 同音高中弱奏原采样：第四谐波 -9.04dB。
- 只改G权重、保留原极点/激励/包络：第四谐波 -9.04dB。
- 两采样半幅脉冲（面积相同）与原版的H4比例仅差约0.03dB，起音10..90%时间几乎相同。
- gamma乘4并重校准G：起音10..90%约107ms，原版约113ms；不是激励单因素对照。

因此本音先尝试中弱奏方向的模态权重更有依据。不能由此证明所有激励设计都无影响，或推广到其他音高。
输出稳态谐波只约束激励频谱与模态响应的乘积，不能唯一反推出两者。
轻奏目标来自同一分析样本；拟合只用于方向试听，不是独立验证。
